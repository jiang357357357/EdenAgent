# Agent 内置共享资料库能力

`lan/directory-sources.ts` 将独立云主机的现有文件夹接入同一持久同步客户端，复用版本、队列、快照和冲突机制；管理员经认证浏览目录并明确确认后绑定。云端目录绑定与各接收端的本机目录相互独立。目录身份变化、符号链接、运行私有目录及重叠源目录会被拦截，旧资料库不会自动选择源文件夹。

`host/` 提供无桌面、无 Core 依赖的独立主机入口。部署种子只含管理员设备 UUID 与公钥，主机持久保存自身身份和权威版本；云端不回连 NAT 后的子机。普通 LAN 模式仍限制私有来源，显式主机连接才允许公网 IPv4、域名及 HTTPS。

SSH 部署协调、认证和异步任务属于 Server；独立主机和安装程序随 AgentServer 构建打包。完整 DLC 携带 x64/ARM64 Node、MonPM 和 C++ 运行库，经 SSH 自动安装到私有版本目录；目标只需基础 GNU/Linux、SSH/SFTP 和目录权限，无需预装应用依赖或下载工具。详见 [云主机与 SSH 部署](../../../DLC/SharedWorkspace/docs/cloud-host.md)。

本包是 AgentServer 的静态工作区依赖，不从 DLC 动态加载。公共入口 `index.ts` 导出目录同步客户端、LAN 运行时及其类型，不依赖 Server 或 Core。

`client/` 拥有目录索引、outbox、快照和冲突/历史恢复；`lan/` 拥有按本机账号隔离的设备身份、发现、配对、密文传输和本机版本服务。具体协议及使用方式见 [SharedWorkspace 说明](../../../DLC/SharedWorkspace/README.md)。

Agent 宿主按账号保存互斥的 `lan` / `cloud` 工作姿态及各自的目录选择。切换前暂停全部目录引擎、取消在途网络并关闭旧监听；云姿态设置 `discovery: false`、`host: 127.0.0.1` 和本机 `canPublish: false`，只使用云主机的权威库。切回局域网恢复 LAN 发现、按 DLC 开关发布及相应目录引擎。两边的身份、配对、绑定和持久队列保留，云端离线不回退本机。独立云主机不传入 `connectionPosture`，继续作为发布服务运行。

运行时必须提供 `active()` 与 `canPublish()`。前者由已验证本机连接控制全部网络生命周期；后者由宿主当前 DLC 清单和显式启用状态控制本机发布。接收和编辑远端获授权的库不受本机 `canPublish` 限制。发布端每次库请求检查该开关，异步内容读写结束后再次检查；仅隐藏 UI 按钮不足以授权或拒绝发布。

不启用发布时，设备仍能发现、配对、读取授权列表及绑定本机接收目录；本机新建与既有库的内容/版本请求被拒绝。启用后恢复既有本机库，关闭不删除数据。每个库的版本由一个发布设备维护，当前没有发布者离线时的多主提交。
