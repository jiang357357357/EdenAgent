# Cua 桌面驱动历史归档

2026-10-23，Eden 的活动桌面执行链由 `@trycua/cua-driver@0.28.0` 改为独立的 Windows Computer Use 实现。本目录按原 Server 相对路径保留 4 个旧 SDK 适配文件及 7 个专属夹具／测试文件，用于追溯旧驱动的会话、坐标与投递行为。

这不是完整的可运行快照；其他历史依赖和共享模块没有复制。归档不参加当前构建和测试，活动代码不得导入这里。当前依赖和发行清单不包含旧 SDK，也没有接入 OpenAI 的私有 `@oai/sky`。

当前实现、测试证据、能力差异与协议切换见[替换记录](../../文档/技术/ts-migration/实施记录/2026-10-23-Computer%20Use%20独立实现与桌面驱动替换.md)。
