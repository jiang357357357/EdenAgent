# Eden Agent Web 前端 — 设计灵感

---

## 整体感受

一个**轻量、现代**的 AI 聊天界面，带有角色陪伴感。

---

## 布局方案

### A. 三栏 (桌面)

```
┌────────┬─────────────────────┬──────────┐
│ 会话列表 │      聊天区域         │   角色    │
│        │                     │          │
│ □ 上午 │  用户消息        👤  │  ┌────┐  │
│ ● 现在 │  助理回复    🤖      │  │立绘│  │
│ □ 昨天 │   _思考:_ 展开 ▼     │  │    │  │
│        │  🔧 vision (4s)     │  │    │  │
│        │                     │  └────┘  │
│ + 新会 │                     │  苏岚     │
│        │ ┌─────────────────┐ │ 19岁     │
│        │ │ 输入...   [发送] │ │ 天才开发  │
│        │ └─────────────────┘ │          │
└────────┴─────────────────────┴──────────┘
```

- **左侧** 会话列表 (可选折叠)
- **中间** 聊天区域 (主内容)
- **右侧** 角色信息 (立绘 + 简介 + 状态)

### B. 单列 (移动端 / 角色模式)

```
┌─────────────────────────┐
│                         │
│       ┌─────────┐       │
│       │  角色立绘 │       │
│       │         │       │
│       └─────────┘       │
│         苏岚             │
│     19岁 · 天才开发者     │
│                         │
│   🤖  今天想聊什么呀~     │
│                         │
│       👤  帮我看看这张图   │
│                         │
│   🤖  看到啦，紫色长发...  │
│                         │
│ ┌─────────────────────┐ │
│ │ 输入框...      [发送] │ │
│ └─────────────────────┘ │
└─────────────────────────┘
```

这是一个独立的界面，只展示角色和聊天框，
没有侧栏，适合手机端或沉浸式对话。

角色立绘在上方或背景中，消息区居中，
输入框固定在底部。

---

## 消息气泡

用户消息：右对齐，蓝色或主题色背景，白色文字。
助理消息：左对齐，浅灰背景，深色文字。
图片附件：在气泡内显示缩略图，点击放大。

消息可以包含：
- 普通文本（支持 Markdown）
- 思考内容（折叠的灰色引用块，左侧竖线）
- 工具调用卡片（折叠，展开看输入/输出）

---

## 思考块

助理消息里的推理过程，默认折叠为一行 `_思考:_ 展开 ▼`。
展开后：左侧细竖线，略深背景色，灰色文字。

---

## 工具卡片

每次工具调用显示为可折叠卡片。默认折叠，一行显示图标+工具名+耗时。
展开后分两段显示输入参数和输出结果。
运行中显示加载动画。失败显示红色信息。

不同工具可配不同图标：vision👁 shell>_ read📖 write📝 search🔍

---

## 输入区

底部固定。支持：
- 多行文本输入（自适应高度）
- 粘贴图片直接显示缩略图预览
- Enter 发送，Shift+Enter 换行

---

## 角色面板

右侧栏（或上方），展示当前 AI 角色的信息：
- 角色立绘（静态图 / 支持切换不同表情）
- 角色名称
- 简短介绍
- 当前状态（可选："在线"、"思考中..."、"刚刚回复"）

---

## 两个界面切换

- **三栏模式**：完整功能，适合桌面、开发场景
- **角色模式**：只展示角色和聊天框，适合沉浸对话、移动端

两个模式通过按钮或响应式断点切换。
