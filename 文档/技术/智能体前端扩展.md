## 使用流程

“前端插件开发”内置技能的名称为 `eden-ui-development`。它通过正常 `list_skills` 目录发现，并由 `load_skill({ name: "eden-ui-development" })` 按需读取，不默认把完整正文放进模型请求。技能说明集中在 `Server/src/model-prompts/ui-plugin-skill.ts`，沿用内置技能构建路径生成标准 `SKILL.md` 快照，开发与独立宿主制品使用同一份内容。

该技能已扩展为统一插件开发指引，覆盖单独 UI、单独连接器及 UI 与连接器或 MCP 后端的组合；保留名称和显示名以兼容既有配置。它负责选择业务状态来源、组件组合、实例绑定、文件编写、安装更新及真实结果验证。`manage_ui_plugins` 和 `manage_connector_plugins` 的 `describe` 继续分别提供实时协议；技能面向普通应用用户会话，可在技能管理中按现有规则启停，不增加权限或改变工具说明加载状态。单独网站或其他源码工程仍按工作区任务处理，不自动安装为应用插件。

组合包在同一 `plugin.json` 声明 UI 和连接器，界面声明所需工具，并使用当前会话可访问的连接器实例 UUID。`build_connector_plugin` 使用宿主提供的 SDK 构建，`manage_plugin_grants` 发起包权限审批，`manage_connector_instances` 创建、配置、申请资源授权和连接当前会话实例；拥有会话也可经审批将实例共享给同账号指定活动应用会话。安装包不等于实例已连接。两个包管理工具的检查快照作用域不同，同一回合应使用同一个管理入口先检查再安装整个包。UI 声明 `read_connector_events` 后，API 1 使用 `host.onConnectorEvent`，API 2 页面使用 `(await acquireEdenApi()).onConnectorEvent` 获取事件提示和重连同步提示，仍须自行查询初始及最新业务状态，并使用 `after` 游标补读；事件与自醒调度受实际配置和限额约束，不代表可靠的即时聊天回合。

`manage_plugin_packages` 提供与组件类型无关的包检查、安装、启停和查询，包括纯 MCP 包；检查与安装仍须在同一工具和回合中使用宿主快照。`manage_ui_plugins.status` 对模块／视图报告附带客户端标识和时间，后台状态另列；`diagnostics` 查询当前会话的近期页面异常与工具调用阶段。API 2 页面报告有限的脚本异常、未处理拒绝、console 警告／错误、CSP 和资源请求失败；API 1 共用渲染上下文，普通 console 不自动归属，React 视图异常仍走原报告。诊断仅驻留内存，容量有限且不保存工具参数和结果；无记录不代表页面或业务成功。

技能接入补充验证：`list_skills → load_skill → describe → 文件编写 → inspect → install` 的录制模型真实工具循环及相关回归共 6 项通过；首次请求仅有技能摘要，读取后才出现完整正文。技能格式、Server 类型及架构检查通过，记录见根 `.run/logs/ui-skill-*.log`。

智能体调用 `manage_ui_plugins` 的 `describe` 获取当前协议、可用插槽、完整 SDK 说明及可直接编写的三个文件模板。通过工作区工具编写文件后，调用 `inspect`，再按插件业务 id 调用 `install`。宿主保留当前回合的检查快照，模型不传递内部 preview UUID 或 revision；安装在审批后复查同一快照。更新时重新检查并安装；`enable`、`disable`、`uninstall` 分别启用、停用和卸载。子任务和 QQ 渠道不提供此管理入口。

`status` 查询当前账号最近 90 秒的浏览器回报，区分模块加载、视图挂载和失败。没有回报意味着尚未获得浏览器证据；加载／挂载回报不代表视觉或业务交互已经验收。

## 包与视图

`plugin.json` 的 `components.ui` 继续指向一个 JSON 文档。既有 `{ schemaVersion: 1, cards: [...] }` 静态卡片保持兼容。新增可执行文档示例：

```json
{
  "schemaVersion": 1,
  "type": "module",
  "apiVersion": 1,
  "entry": "client.js",
  "views": [{ "id": "main", "title": "我的工具", "slot": "sidebar_panel" }],
  "capabilities": { "sessionRead": true, "sessionSend": false, "tools": [] }
}
```

`entry` 从插件包根解析，只接受包内相对路径。文档在检查、安装激活和读取时校验。模块必须是 UTF-8，最大 256 KiB；浏览器再次核对 SHA-256 后加载。TypeScript/JSX 可以先编译为完整 ESM JavaScript，宿主不在客户机隐式安装编译器或依赖。

| 插槽 | 入口与输入 |
| --- | --- |
| `sidebar_panel` | 工作台“扩展”入口中的可并排视图，打开为标签，可移至主区或辅助区 |
| `page` | 工作台“扩展”入口中的独立页面标签，宿主管理分组和关闭 |
| `tool_card` | 现有工具卡片下方；必须声明 `toolNames`，只接收匹配调用的显示数据 |

一个模块可声明多个视图。所有声明视图必须在激活时注册，未声明、重复或缺失注册均使此次激活失败并清理已登记资源。模块失败不会重试执行到下一次轮询；用户可点“重试加载扩展”，或安装修复后的新 revision。

## 组合插件的启用与后台就绪

`manage_ui_plugins.install` 默认安装并启用：宿主按当前权限模式申请当前版本的必需权限，以及已启用 MCP 组件实际需要的进程或网络权限。完全访问下自动通过并记录授权；受限模式仍需现有审批。`enabled:false` 仅安装，不授权、不启动；随后 `enable` 完成授权与启用。连接器包的 `enable` 使用相同授权流程，实例创建、资源权限与连接仍按原实例协议执行。

清单明确关闭的组件保持关闭；`enableComponents:[组件id]` 可明确选择要开启的组件。必需后台应声明 `enabledByDefault:true`，相应权限声明 `required:true`；不得为让 UI 启用而将实际依赖改成可选或关闭。授权与组件变化在同一事务中提交，审批期间版本、组件或权限改变会拒绝旧计划，启用失败回滚新增授权。

安装／启用回执的 `backend.state` 区分 `none`、`disabled`、`starting`、`failed`、`ready`。`status` 同时展示组件、权限和实际后台连接；后台错误保留具体原因。UI 首次使用 MCP 时，宿主在执行工具前等待已启用组件完成初始化，取消与版本失效继续生效，超时返回启动状态错误，不重放写操作。后台就绪不证明外部服务连通或业务成功，仍需验证真实操作。后台失败不得悄悄换用另一份临时或演示数据冒充权威存储。

## 工作台布局

工作台由活动栏、主侧栏、递归编辑器组、工具侧栏、运行面板和状态栏组成。编辑器支持左右／上下组合拆分、跨组移动、合并、标签排序及固定；工具侧栏独立于编辑器树，运行面板可置于上下左右，也可以承载插件页面。窄窗口把打开的页面合并展示，保留原分组以便变宽后恢复。

每个聊天编辑器拥有自己的会话运行时、消息流、输入框、滚动位置和草稿；一个会话标签移动不会带走其他标签。相同插件视图可复制成多个独立实例。普通插件实例固定绑定打开时的会话，切换其他聊天不改变绑定；工具卡片继承所属聊天编辑器的会话。后台审批和采集请求仍由应用统一处理，避免每个编辑器重复处理全局副作用。

聊天编辑器只接收所属会话的消息和恢复快照，不缓存其他编辑器的消息。每个已绑定编辑器持有会话连接引用；五分钟空闲清理不会回收仍打开的编辑器连接，关闭、停用及工作区切换时释放引用。

Ctrl+Shift+P 或 Ctrl+P 打开命令面板，统一执行打开页面、复制实例、保存、关闭、移动、拆分与面板位置调整；Ctrl+S 保存当前实例，Ctrl+W 关闭当前实例，Ctrl+B／Ctrl+Shift+B／Ctrl+J 切换各区域。点击内容或聚焦输入框同步焦点组。内置配置等页面保留各自组件实例，切换后不会丢失尚未提交的表单。

聊天文字草稿自动保存在当前工作区／账号的本机存储中，Ctrl+S 明确保存，保存后关闭可从命令面板恢复；附件不冒充已经持久化，未发送附件会阻止“保存草稿并关闭”。配置页及登记生命周期的插件有未保存标记，关闭时可取消、放弃或保存后关闭；保存回调失败保留页面与标记。窗口退出沿用桌面壳的退出事务，标签关闭确认不改变原生进程退出机制。插件业务数据仍以服务端回执为准。

布局 schema 2 保存递归编辑树、区域位置、尺寸、打开实例及绑定会话，键按世界、服务工作区与账号隔离。schema 1 原侧边标签迁移到工具容器，并从原聊天恢复插件会话绑定。稳定 portal 在切换、缩放和移组时保留实例；关闭实例、停用、升级及账号／世界切换时释放所属调用。

文件区域仍通过原工作区 RPC 提供只读文本预览，本轮不提供文件编辑／保存或任意原生浮动窗口。独立设置、审批和桌宠窗口沿用既有入口。源码位于 frontend/web/src/components/workbench/，聊天消息渲染与历史窗口分别位于 pages/chat/ChatConversation.tsx 和 use-conversation-window.ts。

## 前端 SDK

公开类型入口为 `@eden/plugin-sdk/ui`。模块导出同步 `activate(api)`，可返回清理函数。`api.React` 是宿主的 React；`api.registerView(id, Component)` 注册视图；`api.addStyle(css)` 登记样式；`api.effect(setup)` 管理定时器、监听等资源，setup 必须返回清理函数；`api.signal` 随模块撤下中止。

组件接收 `{ host, tool }`。`host.sessionId` 是当前实例绑定的应用会话，未绑定时为空；`host.signal` 随实例关闭或模块撤下中止。`host.readSession()` 返回会话概要；`host.sendMessage(text)` 返回正常输入链路的接收回执，不承诺模型已经完成；`host.callTool(name, input, { signal }?)` 调用宿主当前注册工具，第三参可取消单次请求而不关闭整个实例。

`host.setDirty?.(dirty)` 登记实例未保存状态；`host.registerSave?.(async () => { ... })` 登记用户保存命令回调并返回撤销函数。保存失败应抛出异常，成功后宿主清除标记；这些方法不增加业务权限。

模块应完整打包，使用宿主 React，避免外部 import、CDN 和重复 React。主题使用宿主 CSS 变量；样式使用自己的类名前缀。插件通过所声明的视图扩展应用；不要修改其他组件 DOM 或绕过 SDK 读取应用令牌、调用内部 RPC。

## 业务与权限

业务服务继续拥有权威状态。SDK 只暴露当前账号的活动应用用户会话，不接受 QQ、后台任务、已归档或其他账号的会话。会话读取、发送和工具调用分别需要文档声明；工具名还必须列在 `capabilities.tools`。

工具调用复用当前会话能力注册表、转发解析、JSON Schema 校验及原工具审批，并额外请求 `plugin.ui.tool` 审批。会话忙时，UI 工具按顺序等待下一个空闲边界，保留原请求只执行一次；宿主显示等待、审批、执行状态并提供取消入口。排队后再次检查会话、版本与授权，角色或工作区选择改变时要求重新确认操作；备忘等独立业务不要求选择文件目录。UI 工具运行时，新消息正常入队，结束后继续；读取会话概要和提交消息不受在途工具阻塞。停止会话或关闭服务会取消等待和正在执行的 UI 操作。

备忘完整列表使用 `list_memos_page({limit, query, cursor})`，返回 `{items, nextCursor, hasMore}`；每页最多 200 条，直到 `nextCursor` 为空。查询变化必须丢弃旧游标和迟到结果，追加时按业务 `id` 去重。原 `list_memos` 保持数组格式与单次上限以兼容旧插件。创建提醒优先使用 `create_reminder`，默认渠道是 `auto`；只有用户明确指定渠道时选择其他值。工具结果包含实际 `delivery`，创建成功和普通聊天回复都不代表提醒已送达，必须核对通信或客户端显示回执。

安装的前端模块属于获准执行的本机插件代码，沿用现有暂停 OS 沙箱的策略；SDK 是调用与生命周期约定，不宣称能限制任意 JavaScript 访问浏览器全局。后端审批、会话归属、组件状态和版本校验继续强制生效。

## 同步、取消与失败

打开的主界面每两秒同步一次轻量目录；宿主按组件、版本、授权和信任状态缓存目录，内容变更才重新装配。模块按插件／组件／revision 替换，先清理旧资源。停止、卸载和世界／账号切换会撤下视图，自动取消未完成的 SDK 调用；前端等待也立即结束。插件自行创建的 fetch、监听及定时器仍需使用信号或清理函数。单次请求的排队、审批与执行共计最多 120 秒；取消不撤销已经发生的外部副作用，结果未知时先核对业务状态，宿主不自动重试写操作。

UI 请求带宿主关联的请求号。发送消息复用正常输入幂等键；完成的近期 UI 请求可重放结果。UI 工具一旦写入执行审计，失败、缓存淘汰或服务重启后不得用同一请求号再次执行，以免未知结果变成重复副作用。相关审计采用 `plugin.ui.action.*`，不伪造模型工具回合。

React 渲染失败由视图自身的错误边界显示并上报，保留重新加载入口；原聊天及其他视图继续可用。模块加载错误在扩展菜单展示。界面回报按账号保留于内存，浏览器关闭或 Host 重启不会伪造仍然挂载的事实。
