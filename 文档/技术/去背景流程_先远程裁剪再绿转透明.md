# 去背景流程：先远程裁剪再绿转透明

## 目标

用于把纯绿背景或接近绿幕背景的角色图处理成透明背景 PNG。

固定执行顺序：

```text
原始绿幕图 -> 远程 BiRefNet 裁剪 -> 绿色残留转透明 -> 最终透明 PNG
```

必须先调用远程裁剪，再进行绿转透明。不要反过来执行。

## 为什么先裁剪

BiRefNet 裁剪负责识别角色主体，生成主要 alpha 透明通道。它需要看到完整的原始背景和角色边缘，才能判断人物轮廓。

绿转透明只负责清理裁剪后残留的绿色边缘像素。如果在裁剪前先把绿色转透明，可能会破坏 BiRefNet 对背景和边缘的判断，导致头发、裙摆、手指、鞋底等边缘识别不稳定。

## 输入要求

- 输入图应为角色全身图。
- 背景应为纯绿色或接近绿幕绿色。
- 角色身上不应使用和背景相同的绿色。
- 长发角色应尽量避免细发丝、封闭发丝空洞和内陆湖式绿色缺口。

相关提示词文档：

```text
D:\rule\gpt\文档\画风\头发轮廓与裁切友好提示词.md
```

## 输出命名

建议保留三个文件：

```text
原始图.png
原始图_BiRefNet透明_日期.png
原始图_BiRefNet透明_日期_绿转透明_日期.png
```

不要覆盖原始图。远程裁剪结果和绿转透明结果都另存为新文件，方便回退和比较。

## 第一步：远程裁剪

默认服务地址：

```text
http://10.8.0.4:40312
```

先检查服务：

```powershell
curl.exe -sS "http://10.8.0.4:40312/health"
```

常规裁剪命令：

```powershell
$in = "D:\path\input.png"
$out = "D:\path\input_BiRefNet透明_20260708.png"
$headers = Join-Path $env:TEMP "birefnet_headers.txt"

curl.exe -sS -X POST "http://10.8.0.4:40312/v1/remove-background/image" `
  -F "file=@$in;type=image/png" `
  -F "precision=fp16" `
  -F "edge_expand=0" `
  -F "alpha_threshold=8" `
  -F "alpha_clip_high=245" `
  -F "preserve_aspect=true" `
  -F "defringe_strength=40" `
  -F "green_spill_remove=80" `
  -D $headers `
  -o $out `
  -w "HTTP_STATUS=%{http_code}`nOUTPUT=$out`n"
```

参数说明：

- `precision=fp16`：使用 GPU 半精度推理。
- `edge_expand=0`：正常裁剪，不额外吃边缘。
- `alpha_threshold=8`：很低透明度直接置 0。
- `alpha_clip_high=245`：高 alpha 区域直接置 255。
- `preserve_aspect=true`：保持原图比例。
- `defringe_strength=40`：去除普通边缘毛边。
- `green_spill_remove=80`：减少绿色溢色。

如果明确需要“吃边缘”，把 `edge_expand=0` 改成负数，例如：

```powershell
-F "edge_expand=-2"
```

不要默认吃边缘。吃边缘会让人物边界略微收缩，适合绿色残留比较重的图。

## 第二步：检查远程裁剪结果

远程裁剪后，先确认输出图是 RGBA，并且四角透明。

```powershell
$out = "D:\path\input_BiRefNet透明_20260708.png"

@'
from PIL import Image
from pathlib import Path

p = Path(r"D:\path\input_BiRefNet透明_20260708.png")
im = Image.open(p).convert("RGBA")
w, h = im.size
alpha = im.getchannel("A")
hist = alpha.histogram()
pix = im.load()

green_visible = 0
for y in range(h):
    for x in range(w):
        r, g, b, a = pix[x, y]
        if a >= 16 and g > 150 and g > r * 1.3 and g > b * 1.3:
            green_visible += 1

print({
    "mode": im.mode,
    "size": f"{w}x{h}",
    "alpha_min": min(i for i, v in enumerate(hist) if v),
    "alpha_max": max(i for i, v in enumerate(hist) if v),
    "alpha_bbox": alpha.getbbox(),
    "corner_alpha": [
        alpha.getpixel((0, 0)),
        alpha.getpixel((w - 1, 0)),
        alpha.getpixel((0, h - 1)),
        alpha.getpixel((w - 1, h - 1)),
    ],
    "visible_greenish_pixels_a_ge_16": green_visible,
})
'@ | python -
```

检查标准：

- `mode` 应为 `RGBA`。
- `alpha_min` 应为 `0`。
- `alpha_max` 应为 `255`。
- `corner_alpha` 四个值应为 `0`。
- `visible_greenish_pixels_a_ge_16` 如果大于 `0`，再执行绿转透明。

## 第三步：绿色转透明

绿转透明只处理远程裁剪后的透明 PNG，不处理原始绿幕图。

执行脚本：

```powershell
$src = "D:\path\input_BiRefNet透明_20260708.png"

@'
from PIL import Image
from pathlib import Path

src = Path(r"D:\path\input_BiRefNet透明_20260708.png")
out = src.with_name(src.stem + "_绿转透明_20260708.png")

if out.exists():
    i = 2
    while True:
        candidate = src.with_name(src.stem + f"_绿转透明_20260708_{i}.png")
        if not candidate.exists():
            out = candidate
            break
        i += 1

im = Image.open(src).convert("RGBA")
pix = im.load()
w, h = im.size
changed = 0

for y in range(h):
    for x in range(w):
        r, g, b, a = pix[x, y]
        if a == 0:
            continue

        max_rb = max(r, b)

        # 只处理明显偏绿色的可见残留，避免误伤白发、皮肤、红色配饰和深色服装。
        if g >= 80 and (g - max_rb) >= 28 and g >= int(r * 1.16) and g >= int(b * 1.16):
            pix[x, y] = (r, g, b, 0)
            changed += 1

im.save(out)
print({
    "output": str(out),
    "changed_pixels": changed,
    "size": f"{w}x{h}",
})
'@ | python -
```

绿转透明规则：

- 已经透明的像素不处理。
- 只处理仍然可见的明显偏绿色像素。
- 不改人物主体颜色。
- 不填补头发空洞。
- 不修正原始生成图。

## 第四步：验证最终结果

```powershell
$final = "D:\path\input_BiRefNet透明_20260708_绿转透明_20260708.png"

@'
from PIL import Image
from pathlib import Path

p = Path(r"D:\path\input_BiRefNet透明_20260708_绿转透明_20260708.png")
im = Image.open(p).convert("RGBA")
w, h = im.size
alpha = im.getchannel("A")
hist = alpha.histogram()
pix = im.load()

green_visible = 0
for y in range(h):
    for x in range(w):
        r, g, b, a = pix[x, y]
        if a >= 16 and g > 150 and g > r * 1.3 and g > b * 1.3:
            green_visible += 1

print({
    "mode": im.mode,
    "size": f"{w}x{h}",
    "alpha_min": min(i for i, v in enumerate(hist) if v),
    "alpha_max": max(i for i, v in enumerate(hist) if v),
    "transparent_alpha_lt_8": sum(hist[:8]),
    "partial_alpha_8_244": sum(hist[8:245]),
    "opaque_alpha_gte_245": sum(hist[245:]),
    "alpha_bbox": alpha.getbbox(),
    "corner_alpha": [
        alpha.getpixel((0, 0)),
        alpha.getpixel((w - 1, 0)),
        alpha.getpixel((0, h - 1)),
        alpha.getpixel((w - 1, h - 1)),
    ],
    "visible_greenish_pixels_a_ge_16": green_visible,
})
'@ | python -
```

最终检查标准：

- `mode` 为 `RGBA`。
- 四角 `corner_alpha` 都是 `0`。
- `visible_greenish_pixels_a_ge_16` 应为 `0`。
- `alpha_bbox` 应覆盖完整人物，不应明显裁断头发、手、脚。

## 注意事项

- 这份流程允许在远程裁剪后做绿转透明，因为用户明确需要清理绿色残留。
- 不要对原始生成图做本地纯绿修正。
- 不要自动填补头发内部绿色空洞；这类问题应该回到提示词重新生成。
- 如果绿转透明后人物边缘缺损明显，应保留原 BiRefNet 输出，并重新生成源图或改用较保守的远程裁剪参数。
- 如果绿色残留很多，可先尝试远程裁剪的 `edge_expand=-2`，再执行绿转透明。
