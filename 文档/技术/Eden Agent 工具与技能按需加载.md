# Eden Agent 工具与技能按需加载

2026-09-13 经用户批准实施，2026-09-14 按用户要求拆分工具暴露与技能阅读状态。活动运行时仍使用当前 OS 账户本机执行。

## 结构

- `Server/src/modules/capabilities/tool-registry.ts`：完整注册表、来源、稳定身份、定义摘要与重名校验。
- `default-tools.ts`：按普通聊天、自醒、子任务及工作区状态选择常驻工具。
- `session-capabilities.ts`：工具发现、加载、卸载、角色技能预加载和恢复校验。
- `selection-repository.ts`：当前数据库内的会话/角色加载状态及持久事件。
- `call-resolution.ts`：通用入口解析到最终工具，检查加载状态及版本。
- `packages/runtime-pi/src/tool-adapter.ts`：最终参数校验、一次操作账本、执行、结果投影。

`tool.list` 保留完整管理目录，并报告来源、实际默认并发方式及 direct/deferred 状态。
模型请求使用会话选择器，不能将管理目录直接当作模型本次可调用列表。

## 模型入口

| 工具 | 行为 |
| --- | --- |
| `list_skills` | 返回当前场景可读取技能的完整摘要目录，并标注缺失的工具依赖 |
| `load_skill` | 读取完整说明及关联工具元数据，报告接口加载状态和缺失依赖；不改变工具接口 |
| `read_skill_file` | 从相同技能快照读取参考文件 |
| `unload_skill` | 停用技能加载记录，保留工具接口和历史说明 |
| `list_tools` | 按关键词分页发现专业能力，返回稳定 id，不暴露内部版本哈希 |
| `load_tools` | 仅按 id 加载当前完整定义，含技能代码工具；逐项返回 loaded/failed；不要求先读取技能 |
| `unload_tools` | 撤销指定工具接口的暴露，基础工具仍保留；不改变技能阅读状态 |

`read_skill` 只保留旧模块调用兼容，不再作为第二个模型工具暴露。
根会话无工作区的本地测试场景：完整目录 53 项，默认模型目录 13 项。数量会随世界、配置和安装的扩展变化。

## 技能目录与基础指引

宿主直接提供简短使用指引，不需要先加载一个“基础技能”来发现其他技能。系统提示动态提供当前可读取技能的名称、简介及依赖状态；摘要最多 96 项、每项简介最多 240 字符，超限提示通过 list_skills 查询完整目录。正文按需读取，当前上下文已有适用版本的正文时不要求重复读取。

目录为空时明确说明没有可读取条目，基础工具仍可调用；目录变化以后以新目录为准。刷新失败保留独立提示，不把上次成功的缓存误报为当前完整目录。

缺少某个工具不隐藏整份技能，也不阻止读取参考文件或操作说明。available=false 表示流程依赖不完整；读取技能只返回说明和关联工具信息，不加载或放开任何工具。禁用、禁止模型调用及场景不适用的技能继续排除。

技能来源保持现有配置：当前世界已安装技能、已启用插件贡献、管理员显式配置的系统目录，以及所选工作区的 .agents/skills 和 .edenagent/skills。宿主附带四份基础技能作为最低优先级来源；若当前场景的基础技能全部被禁用且没有其他来源，空目录是正常结果；不自动导入其他智能体的主目录、旧 Data/skills 或参考项目中的技能。

## 内置基础技能

四份指令技能随宿主构建分发：eden-memory（记忆管理）、eden-reminders（提醒与备忘）、eden-workspace（工作区操作）、eden-self-awake（后台自醒）。正文集中于 model-prompts/builtin-skills.ts，经标准 SkillSnapshot 转为可读取的 SKILL.md；不注册执行工具、不复制参数 schema、不自动执行动作。

普通聊天默认看到前三份摘要；后台自醒可看到记忆、提醒和自醒摘要；子任务可看到记忆、提醒和工作区摘要。依赖不完整仍明确标注，名称和概要并不代表获得执行权限。全文不默认注入系统提示。

同名解析沿用项目已安装、项目发现、用户已安装、插件贡献、管理员系统目录、宿主内置的顺序，只展示胜出的一个条目。内置技能的禁用设置仍保存在当前世界数据库，不修改共享说明源；管理员同名说明优先于内置版本。角色预加载只准备技能记录，不加载工具接口。

## 身份与状态

内置工具 identity 为 `builtin:<name>`，插件为 `plugin:<id>`，MCP 为 `mcp:<runtimeId>:<remoteName>`，技能代码工具为 `skill:<skillName>:<toolName>`。
宿主内部快照绑定 identity、实现 revision、参数 schema 和描述；模型不传递版本字段。工具名仍用于模型调用与角色允许/禁止策略。

schema 115 新增 `session_capability_selections`；schema 116 将原来启用技能中的工具绑定迁移为独立工具选择，保留原始版本与工作区。状态按会话和行动角色分开；单角色与多角色中的同一助手使用一致身份，尘世本地角色另包含角色 ID。
绑定保存技能内容哈希、来源工作区、当前会话工作区和精确工具版本。加载不是审批，也不会恢复旧权限。

工具注册、模型接口暴露、技能阅读记录分别管理。只有有效工具选择决定扩展工具的接口暴露；技能阅读记录不作为调用门槛。工具版本、相关工作区、场景适用性或角色策略变化后，失效工具绑定不进入模型目录，发现入口报告 stale；可单独重新加载工具，不要求重读技能。技能说明状态按内容版本独立检查，不因外部依赖工具版本变化而失效。
重启后复核持久记录。角色预加载使用其已保存技能快照，过期快照保留待重新加载状态。
读取技能只写入技能记录，关联工具绑定用于说明，不参与工具选择。技能和工具各自拥有 96 项启用记录上限，互不占用。显式卸载技能保存停用记录，避免角色预加载在下一轮重新打开该技能，但不会撤销任何工具。显式卸载工具后，即使技能仍处于加载状态，也不会自动重新暴露；只有显式调用 load_tools 才能恢复扩展工具接口。
当前使用显式卸载，不猜测自然语言任务何时结束；历史对话中的技能说明不会被删除。直接调用技能代码工具仍校验其启用状态、场景、快照版本和审批，但不要求其他工作流依赖工具全部可用。

## 调用与权限

1. 模型选择一个当前可见入口。
2. 通用入口解析最终目标；同时检查入口和目标的可见性与角色策略。
3. 公共适配器校验最终工具的参数，按最终工具名称与版本记一次预算和操作账本。
4. 业务模块按具体能力请求审批，审批服务在批准后复查工具绑定和策略。
5. 模块继续核对插件激活版本、MCP 运行时、技能快照和连接器 generation，然后执行。
6. 结果持久化后交给模型。内部转发不重复创建逻辑操作或扣工具预算。

通用技能/MCP/插件入口不能绕过针对具名工具的禁止规则。`switch_assistant` 始终属于根会话专属工具。
发现与加载是会话能力选择，不提供额外 OS 文件或网络隔离。副作用仍走已有审批及具体资源授权。

## 结果

公共操作记录支持 completed、failed、cancelled、unknown。
MCP 的 `isError` 结果和非零命令退出码进入 failed；外部连接断开或进程停止后无法确认的执行结果进入 unknown。
审批阶段明确取消进入 cancelled；已提交的审批决定与后续执行取消保持独立。
原始结果用于账本，模型投影单独处理。MCP 图片字节通过图片块发送，文本不重复包含同一份 base64。

## 验收范围

自动化使用内存数据库、临时磁盘数据库、本地录制模型 HTTP 服务及真实 Node 技能进程。
不读取或升级真实用户数据库，不调用真实付费模型、外部账户或游戏，也不发布安装包。
最初实现与测试见实施记录 75；工具与技能解耦修正见实施记录 76。
