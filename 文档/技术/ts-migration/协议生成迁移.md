## 当前事实来源

- `packages/api/src/rpc-methods.ts` 汇总各业务输入/输出 schema，`SchemaRpcMethodMap` 从注册表推导。
- `packages/api/src/connection-rpc.ts` 定义初始化结果和共享通知表，通知类型由 `SchemaRpcNotificationMap` 推导。
- `frontend/web/src/lib/rpc-contracts.ts` 只使用共享方法表，输入和返回值均校验；不存在旧方法类型回退或缺少契约时跳过校验的分支。
- `frontend/web/src/lib/rpc-client.ts` 直接导入共享方法、通知和世界类型，不依赖未重新生成的旧客户端类型。
- `frontend/web/src/lib/blob-upload.ts` 使用当前 BlobInfo/schema 校验上传结果，生成模板重导出同一实现；来源摘要已纳入该文件。未实际上传或生成。
- `Script/Project/templates/rpc-browser.ts.template` 的方法/通知映射直接指向共享类型；旧具名数据类型仍从 legacy-wire 重导出，供尚未改完的视图映射使用，不能作为新方法契约来源。
- `Script/Project/generate_rpc.mjs` 读取 API 源码、模板及浏览器传输实现，计算来源摘要后原子写入生成文件。根 generate:rpc 使用 Node，不调用 Cargo、宿主或数据库。

本轮只对旧清单 83 个方法名称做源码定位：都能找到路由和共享 schema 声明；初始化/ping 使用未加引号的对象键，另行阅读定位。当前前端源码没有 declare module 类型扩展。名称存在只证明声明覆盖，不能证明参数、返回值、副作用和历史行为完整兼容。

## 浏览器传输

连接处理 open/error/close 和 15 秒超时；旧连接事件绑定原 socket。请求默认 120 秒超时、最多 256 个等待项，序列化和发送失败清理等待状态。断线/超时只结束本地等待，结果未确认的副作用不能自动重试。

入站响应检查 JSON-RPC 版本及 result/error 互斥；未知迟到响应不改变已结束请求。通知回调隔离异常，BigInt 超出安全整数拒绝转换。当前前端已直接引用此传输源码，生成模板重导出同一实现。
