# 连接器统一实施计划

状态：2026-09-10 用户批准；本轮实现与 Linux 集中验收完成，跨平台和真实游戏环境验收另列。此文档是本轮工作清单；原有目录归并和 682 项测试记录不代表本轮验收。

## 目标与边界

连接器是插件包的一种运行时组件。官方、用户编写和智能体生成的连接器使用相同的包校验、版本选择、组件启停、实例授权和隔离生命周期。宿主根据协议与资源声明启动组件，不根据游戏名称选择实现。

保留两层授权：插件版本批准其声明的能力，连接器实例批准解析后的具体路径、端点和身份。更新版本、修改设置或撤销任一授权后，旧实例不能继续调用。凭据仅注入对应隔离进程，不进入模型上下文和公共事件。

## 实施顺序

1. [x] 通用 TS 连接器 SDK：帧协议、初始化、健康、查询、动作、事件、关闭、背压和错误边界。
2. [x] 插件包支持 `connector` 组件及 Node 入口；统一完整包快照、摘要和组件发现；原 native_worker 仅作为显式兼容入口。
3. [x] 资源声明驱动的启动器：文件挂载、身份、受限网络桥接；移除宿主游戏名称分支。网络隔离不得因 TS 化放宽。
4. [x] 官方四个实现迁至 TS 插件，逐项保留协议和业务；共享能力按职责放入 SDK，游戏规则留在插件。
5. [x] 智能体创作与安装闭环：编写包、构建、隔离测试、预览安装、版本授权、启用、自动发现。禁止生成代码自行批准权限。
6. [x] 构建与桌面发行改用 Node 制品；归档仍被使用的 Rust 源码后撤下活动 Cargo/Native 依赖；更新工程说明。
7. [x] 集中测试：协议与故障、任意名称第三方包、版本撤销、权限隔离、游戏协议本地模拟、构建与宿主回归。

## 文件组织

- `packages/plugin-sdk/src/connector/`：公共合同、帧编解码、worker runner；通过公开子入口导出。
- `Server/src/modules/plugin-market/packages/`：已有安装与版本所有者，扩展组件类型，不创建第二个安装数据库。
- `Server/src/modules/connectors/`：实例、事件、授权、通用资源绑定与进程协调。
- `Server/connectors/official/<id>/src/`：对应业务的 TS 实现；`package/` 保存清单和资产。
- `packages/execution/`：可信进程沙箱和不可变快照，不依赖 Server 或游戏代码。

文件按协议、状态、传输、动作拆分，生产和测试 TS 均受 500 行上限、复杂度 15 门禁约束。不能通过压缩代码、编号拆片或豁免绕过门禁。

## 验收标准

第五个任意名称的连接器包无需修改宿主即可安装、授权、运行、发布事件与退出。未批准资源不可访问，摘要变化必须重新批准，禁用插件能终止实例。四个旧连接器对外能力清单不缩水。活动构建不得要求 Cargo；归档 Rust 不计为运行依赖。真实游戏、外部账户及其他 OS 未运行的项目必须明确标为待环境验收，不以本地模拟代替。

## 当前进展

已核对：现有官方目录发现硬编码四个名称，生命周期按名称分派三个专用启动器，已安装 native_worker 使用另一条通用文件挂载路径。现有版本完整性和实例授权机制可复用。约 4,920 行 Rust 协议及游戏源码已归档，活动四个 worker 改为 TS；Windows 输入相关 .NET interop 由插件持有，实际 Windows 隔离支持与验收仍未完成。

## 已落地的运行规则

- `connector` 组件使用 `runtime: node` 和 `entrypoints.node`；`native_worker` 仅保留显式兼容协议，不包含官方名称特判。
- 包安装仍使用 `plugin_packages`、`plugin_package_selection`、已有包权限表，不另建连接器插件版本仓库。官方目录只是随发行提供的可安装包与清单目录，不能直接执行；旧实例别名在其所属插件启用后解析到该组件。
- 版本选择默认禁用；必需包权限未批准不能启用；任何实例权限也必须有同版本的包级授权。包内容或版本变化后旧实例资源摘要无效。
- HTTP 绑定声明设置字段与默认 URL；TCP 绑定声明 loopback、主机/端口设置字段，可从已批准的实例注册文件读取，受管实例绑定 PID 启动标识。每条 TCP 桥接固定一个已解析地址，插件不能另选目的地址；批准的 URL/loopback 权限是端点权限，不是 HTTP 路径白名单。
- `manage_connector_plugins` 提供创作协议说明、预览、安装、启停与列表；源码写入、构建和测试使用已有工作区工具/执行审批。安装只消费预览保存的确切包快照，工具不提供权限自授入口。
- Victoria 3 控制要求文件写权限与 `desktop.input application:victoria3 control` 两项授权；当前 Linux 连接器沙箱不支持桌面输入。TS/PowerShell 实现、ACK 匹配和失败清理已编写，实际 Windows 前台窗口控制不计入本轮通过项。
- 根 `Native`、Cargo workspace 与四个 Rust worker 已移至 `Archive/2026-09-10-rust-connectors` 并保存 26 文件的 SHA-256。Windows 桌面指针观察器属于另一组件，仍有独立 Rust 构建，不能把本轮描述为整个仓库完全没有 Rust。
