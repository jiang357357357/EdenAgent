## 新增验证与复现

新增 `frontend/web/tests/model-usage-display.test.mjs`：实际执行模型响应投影、session reducer、重新加载映射，并通过 React 服务端渲染验证空输入时上下文圆圈仍显示占用百分比、未知分类不伪装成零。

扩展自醒请求分组测试，模拟重复投递请求/工具事件、只有工具结束的残缺记录。扩展服务端用量测试，模拟有效响应后紧接一个没有 usage 的失败响应。修复前新增的三类回归都失败，修复后通过。

## 修复缺陷

1. 自醒分组未去重：重复请求产生相同 key 的分组，重复工具开始导致数量膨胀。现在按请求 ID 与调用 ID 去重；重复开始不覆盖既有结果。
2. 工具结束事件没有对应开始时，解析已有结果却未在分组视图展示。现在作为未关联调用展示，并使用结束事件提供的工具名称。
3. 重新打开会话只读最后一条 model.response，若其 usage 缺失则丢弃之前有效的统计，和实时界面行为不一致。现在恢复最后一条含有效输入/输出计数的响应。
