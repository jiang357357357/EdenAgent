# 暂停沙箱，统一本机执行

日期：2026-09-10。用户明确要求暂时停用全部执行沙箱，并备注开发者审阅后才能加入。

## 当前行为

终端命令、单文件工具插件及其测试、工作区写入、技能代码、MCP stdio、连接器 worker、Git 源获取均由当前 OS 账户的本机进程执行。取消 Bubblewrap、prlimit、Node permission 和 jitless 启动限制；网络和文件访问由 OS 账户权限决定，不自动提权。

旧沙箱设置在读取时被当前 host 策略覆盖，不改写用户数据库。设置 API 拒绝重新选择 sandbox；原外部沙箱环境变量不会影响启动。UI 只展示本机执行状态，尚未重启的旧服务会明确提示重启，不把旧状态伪装成新状态。

插件 context.workspaceRoot、工作区写入、连接器资源设置/dataDirectory/桥接 socket、MCP package/cwd 均解析为真实本机路径。MCP 支持本机 PATH 程序和绝对可执行文件。子智能体 workspace-write 不再强制要求隔离终端；read-only 等工具白名单属于业务策略，继续保留，不代表 OS 隔离。

## 保留与暂停范围

- 保留审批、输入校验、版本/摘要校验、插件测试及激活流程、进程生命周期、超时、输出限制、取消与 Windows 进程树终止。
- 保留按世界显式注入的凭据，不自动将宿主模型凭据批量加入子进程环境；这不提供本机文件隔离。
- 工作区文件工具仍校验所选路径，防止误写；本机终端和插件可以通过 OS API 访问工作区外文件。
- 包权限/资源授权继续控制宿主是否启动、注入配置或调用工具。已启动的本机代码内部文件/网络/子进程操作不受沙箱约束，不能宣称每次内部副作用都有独立审批。
- Electron 渲染进程和浏览器 Blob CSP 不属于智能体执行沙箱，本轮不调整。

## 恢复要求

原实现与旧隔离测试以 `.disabled` 文件保留在 `Archive/2026-09-10-sandbox-paused`，不参与编译、运行。活动兼容入口 `probeSandbox` 返回 unavailable；`sandboxArguments` 和外部隔离适配器的调用被禁用，不是假装隔离成功。

**沙箱机制必须经开发者审阅后才能重新加入。** 没有用户界面、环境变量或模型可切换的重启沙箱开关。审阅范围见归档 README。
