# 网页引用写入列数错误

日期：2026-10-06。模块：Server 网页引用持久化。

## 原因与修复

`web_resources` 自 schema 126 起有七列：session_id、ref_id、kind、url、title、body、created_at。`WebResourceRepository.put` 原 SQL 的 VALUES 仅有六个占位符，但 `.run` 传入七个参数。SQLite 在 prepare 阶段即报 `table web_resources has 7 columns but 6 values were supplied`；搜索与网页获取共用此写入，因此均可能失败。

将 INSERT 改为明确这七个列名并提供七个占位符。不修改表结构、已有引用、账号或会话记录，权限与按会话最多保留 128 个资源的行为保持原有实现。
