# 业务工具参数与宿主职责分离

日期：2026-09-14。

## 修改

- write_file 移除 expectedSha256，read_file/write_file 不再返回内部哈希。WorkspaceService 按会话、回合及行动角色保存读取快照；写入使用该回合已读快照，未读取时在审批前取得当前基线。执行前仍比较哈希，原本不存在的文件强制使用只创建模式，防止等待审批时出现的文件被覆盖。成功写入后更新该回合快照，跨回合或重启后的编辑会重新取得基线。
- 移除模型目录中的 mark_memo_triggered 和 dispatch_due_memos，真实投递状态仍由宿主调度业务更新。备忘创建/修改不再接受任意 metadata；create_reminder 不再暴露会被强制覆盖的 kind。
- spawn_agent 只暴露 taskName/message/role；会话、行动角色、幂等键由宿主注入，资源上限由协议默认值、角色策略与祖先预算约束。
- 拨号只使用 reason/currentSituation/suggestedOpening；title/text 仍用于消息及通知动作，拨号分支不再接受兼容别名。模型 schema 保留对象根并携带各动作参数分支约束。
- 插件模型 draft 只接受 manifest/source，read 自动记录本回合当前行动角色的草稿版本，validate/test 只接受 id。宿主在提交及审批后使用已记录快照检查冲突；当前回合未读取的已有草稿不能被不同内容盲目覆盖。安装、激活、回滚的精确制品版本仍保留。
- 更新文件操作说明、插件开发指南及冲突报错。管理端 RPC、持久化 schema 和权限接口没有删除相应内部字段。
