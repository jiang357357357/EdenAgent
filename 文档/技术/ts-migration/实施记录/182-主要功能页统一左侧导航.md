# 182：主要功能页统一左侧导航

日期：2026-10-07。模块：AgentFrontend 主页面布局及共享资料库导航。

**已按用户纠正撤回。** 用户需要共享资料库页面内部的子功能导航。该记录仅保留曾执行方案与验证历史，不代表当前界面；新增主导航、共享直达入口及其他页面根布局改动已全部恢复。当前实施见 [183：共享资料库页面内部子功能导航](183-共享资料库页面内部子功能导航.md)。

## 页面行为

用户指出共享资料库页面缺少最左侧导航，难以区分并切换功能。已有 `Sidebar` 中的主导航提取至 `ActivityRail`，由 `MainPageLayout` 放在页面替换和滚动区域之外。主窗口保留同一主导航实例，当前功能使用强调色、左边标记及 `aria-current="page"`；补齐备忘、技能、连接器、角色选择和设置的当前位置，并增加共享资料库与插件入口。配置、设置及退出保持在底部，上部功能在短窗口中独立滚动。

主导航负责切换功能，共享页内部资料库列表继续负责选择资料库。工作区、所有会话与配置页通过 `showNavigation=false` 关闭原有内嵌导航，保持单一主导航；单独使用这些组件时仍兼容旧布局。工作区内容栏扣除已外移的导航宽度，原会话列表/文件区保持原宽度。原覆盖整个视口的页面根节点改为填满父容器，给导航留出空间。登录、世界选择、桌面角色、独立设置及问题窗口保持自身入口和布局。

## 实际目录与失败行为

`useSharedWorkspaceNavigation` 只拥有导航读取的忙碌状态、错误和请求代际。点击“共享”调用已有 `getWorkspace(sessionId)` / `workspace.info`；只在服务端返回 `ready` 和实际 `path` 后进入共享页面，不使用缓存目录替代缺失的后端能力，也不创建会话、选择库、绑定或上传文件。没有会话时入口禁用并给出提示；可到文件页创建或选择会话。读取失败或目录不存在保留当前页面并显示可关闭的原因，可再次点击重试。

重复点击只保留一次读取；共享页内点击自己的入口不重新挂载页面。后续切页、会话、账号、世界及本会话的目录改变取消旧读取，卸载后的回复无效；其他会话的目录通知不影响当前入口。运行时身份修订继续保护离开再返回同一世界的情况。既有共享绑定、目录切换竞态修复和静默轮询保持生效，没有修改共享协议或用户数据。
