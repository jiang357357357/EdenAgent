## 已准备方案

目标为 `C:/Users/Lenovo/.wslconfig`，候选配置为：

```ini
[wsl2]
networkingMode=mirrored
autoProxy=true
```

配置解析校验通过。Microsoft 文档说明镜像网络允许 WSL 通过 127.0.0.1 连接 Windows 服务，autoProxy 继承 Windows HTTP 代理；`.wslconfig` 更改需停止并重新启动 WSL VM。参考：[WSL 网络](https://learn.microsoft.com/en-us/windows/wsl/networking)、[配置与重启规则](https://learn.microsoft.com/en-us/windows/wsl/wsl-config)。

维护流程：确认相关输入空闲，或取得立即中断当前 WSL 工作负载的明确选择；确认原配置仍不存在并保存回退状态；写入候选配置，暂停并在切换后恢复已有 8123 监管任务；重启 WSL。8123 由现有 systemd 单元恢复。8137 若在重启前仍存在，则用原账号、目录和参数恢复为仅本次启动生效的服务，不设置永久开机自启。保留 Windows 侧 Core/Agent/MonOs 的进程和现有所有权，不因网络维护改变 MonPM 期望状态。
