# 多会话隔离与自主工作区选择

2026-10-04。承接“开始完成彻底隔离，防止影响”，按用户补充要求将文件夹交给用户逐会话选择。以下为源码实现及隔离测试记录；该阶段未替换客户制品。

后续用户要求更新便携包后，本机 `EDEN-portable/EDEN_win` 已在当日 19:22 完成配套构建更新与服务恢复，现场核对保留 2 会话和 2564 条历史事件，schema 132 和会话自醒协议 2 生效。正式客户归档未更新。详见根仓库[本机更新记录](../../../../../文档/发布/Windows便携分发构建与发布记录.md)。

## 用户可见行为

- 可“新建会话并选择文件夹”，也可在已有会话选择或更换目录；只改变该会话。选目录不调用模型，取消后保留空会话，不自动创建专用目录或搬动原文件。
- 伊甸园空会话首次发送时，先绑定用户当次选择的助手及模型，再向原会话发送；缺少助手时明确提示配置。切换标签、账号或世界不会把迟到结果写入另一个会话。
- 文件浏览、文件工具、命令、项目技能、项目角色、子任务和共享资料库使用所属会话的目录。目录切换使该会话的旧预览和角色缓存失效；运行中的同会话操作仍有切换保护。
- 两个会话可以主动选择同一目录。此时内容有意共享，冲突通过路径锁、文件哈希和修订校验处理；选择不同目录才能分开文件内容。
- 旧会话升级时保留原账号的目录选择；新会话以账号默认选择建立独立快照。默认便携目录随包重定位，外部目录缺失时明确报错，不能自动改成其他目录。

## 隔离边界

### 连接与恢复

前端保留一个轻量控制连接，使用中的会话按需创建独立 WebSocket、请求队列、事件序号和恢复游标。服务端核对绑定的 sessionId，禁止在会话连接执行账号级管理变更。账号/世界切换关闭旧连接；不为全部历史会话预先建立连接。

缺序补发、重新鉴权、发送积压或请求队列满只关闭所属连接。发送积压超过 4 MiB 使用 1013，普通队列超过 64 项使用 1008；停止请求保留优先通路。首次订阅前的事件从持久记录补发，避免“创建后、连接前”漏消息。

健康检查仍报告会话故障数量，但单个会话故障不再直接让整个账号返回未就绪。真正的账号或宿主故障仍返回失败。

### 模型执行

生产回合、角色执行、压缩、标题、规划及记忆文本请求转入独立 Node 子进程。父进程保持经过认证的工具、审批、写入和事件持久化；子进程通过私有 IPC 请求这些能力，并等待持久化确认。

子进程每秒心跳；默认失联 15 秒、启动 60 秒超时，取消等待最多 2 秒后终止。每个子进程限制 V8 old-space 为 512 MiB，正常完成释放；独立父进程监测线程在宿主退出后清理模型子进程。上述内存值不是操作系统总内存配额，也没有硬 CPU 配额。

工具实际名称、修订、参数校验、模型结果投影和调用前缀保留原语义；持久化失败后停止所属执行，不自动重试已经发生的副作用。IPC 回调保留账号上下文。辅助文本请求显式关闭供应商自动重试，避免上层不知情的重复调用。

### 工作区与共享同步

schema 132 增加 `session_workspaces`，以 sessionId 保存选择与 revision；技能预览、角色导入等同时绑定目录修订。`workspace.info/list/read` 等调用必须明确 sessionId，匹配的新前后端需一起部署。

文件、目录及包含关系使用共同的路径冲突队列，不相关路径可以并行；等待审批期间改过目录，即使又切回来，旧 revision 也会被拒绝。项目技能目录按会话维护，系统/用户目录继续属于账号级公共配置；会话执行不能通过项目接口悄悄修改公共技能。会话结束后释放项目技能服务。

共享同步实例固定在 canonical root，切换标签或更换会话文件夹不会把原同步队列指向新目录。已绑定目录后台继续同步；账号私有 `shared-workspace/folders.json` 保存稳定身份及 managed/external 标记，不含凭据。重新登录后仅读注册表恢复，不扫描所有历史会话。缺失外部目录独立记录故障，其他目录继续；默认目录随便携路径重新定位。旧版单默认绑定首次连接时登记迁移。仅空闲未绑定实例采用 32 项淘汰上限，已绑定实例保留。

### 自醒

schema 131 将待执行计划、运行占用、取消、替换、恢复、实际激活和发布修订按 session 隔离。MonOs v2 请求携带目标会话及已批准作业，通过签名和归属校验激活原作业，不根据 Core 当前助手临时新建会话。

MonOs 在 `sessions/<uuid>` 保存各自请求、状态及激活信息；发送前持久化完整幂等请求，丢回执或重启后复用同一请求。单目录坏结果或发布失败不会中止其他会话。旧 v1 根调度保留独立范围；升级通过 `legacy_request_id` 撤下对应旧根计划，防止同一计划重复触发。显式未来时间不被十二小时兜底提前。

`session-protocol.json` 带 `expiresAt`：30 秒能力租约、每 10 秒续期、正常退出删除自己的实例标记。旧 MonOs 或过期能力不能被误认支持会话隔离。需要同时部署配套的新 Agent 和 MonOs。

本轮没有推进产品版本、提交推送、构建完整客户包或重启客户服务。源码测试不等同于当前客户便携包已经修复；正式交付仍需构建匹配组件、全新解压及客户流程验收。

## 未消除的共享资源

账号 SQLite、工具宿主、操作系统、磁盘与外部 Core/供应商仍然共享。同步 SQL、磁盘锁、宿主工具阻塞或整机资源耗尽仍可能影响多个会话；本轮不是 OS 沙箱，也不提供文件系统/网络安全隔离。同一目录下不经应用工具执行的外部程序，不能只靠应用路径锁防止冲突。

未执行实际双机局域网、Electron 可见界面、客户 11 GB 数据库或长期高并发浸泡测试；当前证据不能用于承诺“永不离线”或具体承载上限。BaseOs 两个既有 BGE/FAISS 资源测试因资源条件跳过，未安装缺失 rustfmt。新数据库 schema 不支持直接交给旧程序回滚。
