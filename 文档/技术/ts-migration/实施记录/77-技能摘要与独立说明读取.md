# 77 技能摘要与独立说明读取

日期：2026-09-14。用户批准对照本地参考框架后修正技能发现链路。

## 定位与实现

只读检查当前伊甸园 v2 数据库，installed_skills 为空。宿主没有默认技能包；系统根目录要求按世界显式配置，项目目录取所选工作区的 .agents/skills 和 .edenagent/skills。真实请求曾包含“可用技能摘要：[]”，不能据此声称已向模型提供具体技能，也不能把空目录自动视为加载故障。

保留“宿主简短指引 + 动态摘要 + 按需正文 + 独立工具注册表”。本轮未新增用于介绍其他技能的默认基础技能，也未从旧数据或其他智能体的目录安装技能。

修复内容：

- 原来技能缺少任一工具依赖就被摘要和 list_skills 隐藏，读取正文也失败。现在保留可读取技能，提供 available/missingTools；正文和参考文件可独立读取。
- load_skill 只顺带加载当前注册表中存在且策略允许的工具，并报告缺失依赖；不会因技能声明而恢复被禁止的工具。启用状态、模型可调用性、场景、版本和执行审批仍有效。
- SystemCapabilities 原先覆盖 list_skills 的 promptHint，导致技能来源刷新失败提示丢失。现在保留独立刷新错误说明，恢复成功后去除。
- 提示区分空目录、依赖缺失、刷新失败及加载记录过期。超过 96 条时说明已截断，并指向 list_skills 完整目录。
- 新目录替代旧目录；模型不得按摘要猜测正文，当前上下文已有适用版本正文时无需重复读取。

状态仍由世界数据库中的技能仓库、目录服务和会话/行动角色能力选择器各自持有。没有 schema 变化，未修改真实用户数据或启动服务。
