# 75：工具注册表与技能按需加载

日期：2026-09-13。用户批准少量常驻工具、会话级能力加载和统一执行入口后实施。

## 实现范围

- 新增 capabilities 业务模块，分开完整注册表、会话选择器、加载状态 repository 和最终调用解析。
- 内置、插件、MCP、技能工具使用明确来源和稳定 identity；注册表统一实际默认串行语义。
- 普通聊天、自醒、子任务和工作区采用不同基础工具集合；低频工具保留发现入口。
- 新增 list_tools/load_tools/unload_tools/unload_skill；load_skill 读取说明并加载依赖，read_skill 保留内部兼容。
- 技能目录和提示摘要按当前角色可用依赖过滤，列表不再携带完整代码工具定义。
- schema 115 保存会话/行动角色加载记录，绑定内容、定义摘要和工作区。单/多角色同一助手身份一致，本地角色分开。
- 加载、卸载写持久事件；共享依赖按所有有效来源保留。重启重新校验，过期绑定显示 stale；角色预加载与显式卸载采用同一状态表。
- 通用技能/MCP/插件入口解析最终目标，再校验参数及子任务策略，只记一次逻辑操作与预算。
- 审批前后复查工具版本、加载状态和角色策略；修正根会话专属助手切换工具的旧名称失配。
- 公共结果支持 completed/failed/cancelled/unknown；MCP 业务错误和非零终端退出记为失败，结果不明确时保留 unknown。
- 原始结果保留在账本，MCP 图片投影不再把同一份 base64 重复塞入文本。
- 更新插件/助手切换录制测试，先加载专业工具，再调用；迁移夹具不再假定旧工具名迁移永远是最后一个迁移。

## 状态归属与失败行为

输入：会话、行动角色、场景、工作区、工具定义、技能快照和已有角色策略。
输出：当前请求可见工具、分页发现元数据、持久加载记录及操作结果。
状态所有者：capabilities repository 拥有选择状态；技能与扩展模块继续拥有各自版本及审批资源；runtime-pi 拥有模型调用适配。
失败：缺失依赖、策略禁止、版本变化及工作区变化不自动扩大权限或改绑。审批期间变化拒绝执行；明确审批取消与执行结果未知分开记录。
