# 统一实际自醒与十二小时截止时间

2026-09-14，用户要求工具安排下一次自醒；没有安排则兜底，距最近一次实际自醒最多 12 小时必须再醒一次。

## 所有权与规则

- Agent 从 self_awake_runs 对应回合的第一条 agent.agent_start 持久事件提取真实开始时间，发布 `agent_activation.json`。排队、重试准备和只设置定时不能冒充已经醒来；同一运行多次启动事件取第一次。
- 发布器启动及定时重试均从持久数据重建，原子覆盖自己的快照，不写 MonOs 的 state.json。快照内容未变不重复写文件。
- MonOs 在控制轮询和到期检查前读取快照，只有更新的开始时间才移动基准；重复读取与进程重启不延后截止时间。
- 新一次实际自醒使旧兜底/退避计划更新为开始时间加 12 小时。仍有效的更早工具计划保留。超过截止时间的计划继续由看门狗收紧。
- 成功完成的较新实际自醒确认后，清除已过时的连续失败计数和当前错误；旧事件和日记原样保留。不会修改仍被轮询的作业 ID。
- Agent 自己计算工具时间上限时也采用本地最新真实开始时间与外部基准中的较新值，避免等待 MonOs 下一轮同步期间沿用旧截止时间。
