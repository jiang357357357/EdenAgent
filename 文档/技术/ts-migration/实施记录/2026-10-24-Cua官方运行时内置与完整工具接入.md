# Cua 官方运行时内置与完整工具接入

Eden 已改为直接内置官方 `@trycua/cua-driver@0.28.0` 和 Windows 原生运行库，完整登记该版本目录中的 56 个公开工具。用户不需要另装 Cua 应用、服务或 npm 包。此前自行编写的 C# Computer Use 执行器已退役归档，不进入新构建和发行资源；输入观察器继续独立保留。

本轮完成代码、构建、自动化和独立目录原生验证。在线 Server、共享 broker 及客户运行副本尚未切换；真实前台键鼠、QQ 和硬件接管验收仍按既有要求暂缓。公开工具接通不表示每项平台能力都已实际操作成功，平台不支持的功能保留 Cua 的明确拒绝。

## 内置方式

执行链为 `Eden 工具 → Eden 权限与审计 → 共享 broker → 受管 cua-worker → 官方 SDK → 官方 Windows 原生库`。worker 使用 Eden 自有 stdio 协议，随宿主启动和关闭。进程边界用于处理原生崩溃、超时和资源清理，不要求独立安装外部服务，也不提供 OS 沙箱。

`Server/package.json` 精确固定 SDK 0.28.0 和 Ajv 8.17.1；根锁文件固定平台与 UniFFI 依赖。Server 构建生成 `cua-worker.mjs`，发行依赖计划收集官方 SDK、Windows 原生库及 N-API 支持包。制品清单登记 worker、broker、观察器和 MIT 许可的 SHA-256。包内不再包含独立 C# 执行器。

`cua-catalog.json` 来自实际 SDK 的 `listToolsJson()`，保留上游 schema、说明及能力元数据；`packages/api/src/cua-tools.ts` 提供精确名称清单。每次原生实例创建时核对全部 56 项名称与参数契约，差异会阻止执行。升级时运行 `generate_cua_catalog.mjs --write` 后审阅，不自动追随上游主分支。

源码对照固定为 Cua 标签 `cua-driver-rs-v0.28.0`，提交 `1b50c02e2d34734f64d2d22f54eb76cc97b4a663`。参考克隆不是运行依赖，发行验证在没有 `Server/src` 或参考仓库的临时目录启动。

## 工具覆盖

| 类别 | 接入内容 |
| --- | --- |
| 应用与窗口 | 发现、启动、终止、激活、调整窗口、菜单、窗口诊断 |
| 观察与输入 | 窗口／桌面截图、无障碍树、状态验证、缩放、点击、拖放、文字、按键、滚动 |
| 浏览器 | 准备连接、状态与页面、导航、点击、输入、对话框、文件上传、下载和指针操作 |
| 剪贴板与指针 | 读取／写入、指针定位、智能体光标开关、状态、主题与运动配置 |
| 录制与回放 | 开始／停止录制、录制状态、轨迹回放、FFmpeg 安装 |
| 配置与生命周期 | 权限／健康报告、读取／修改配置，以及全部公开会话工具 |

56 项以 `cua_<上游名称>` 注册，保留上游行为。初始请求只展示常用说明，其他工具可发现并加载说明；已知参数时仍可直接调用已注册工具。`load_tools` 不参与驱动安装或启用。

统一技能入口为 `cua-computer-use`，可通过 `list_skills` 发现、`load_skill({name:"cua-computer-use"})` 读取。技能以一个 `SKILL.md` 关联全部 56 项 Cua 工具和 10 项兼容接口，说明如何选择工具、观察并操作目标、核验结果及处理未知／暂停；不复制整份参数目录，不增加可执行辅助脚本。源说明集中在 `Server/src/model-prompts/cua-skill.ts`，由内置技能快照机制随宿主打包。

读取技能不批量展开参数。真实宿主验证发现技能、读取流程、按需加载一个工具、卸载说明的请求中，Cua schema 数量依次为 `0、0、0、1、0、0`；仅指定的 `cua_get_window_state` 展示完整参数。技能层结构校验、相关 8 项测试、类型、构建和架构检查通过，独立证据为 `.artifacts/cua-skill-20261024/verification.json`；没有真实桌面操作或在线重启。

原 10 个 `desktop_*` 继续作为兼容接口，其 schema 修订为 `eden.desktop.cua.v5`。默认恢复为后台投递，明确的前台请求才交给 Cua 前台执行；后台不可用不会自动重试。单个按键映射至 `press_key`，组合键映射至 `hotkey`。跨窗口拖放直接使用 `cua_get_desktop_state` 后调用 `cua_drag(scope=desktop)`；兼容接口拒绝推测窗口裁剪图到桌面的原点。

## 宿主边界

所有调用继续经过任务授权、当前作用域检查、持久操作审计、双世界串行仲裁及暂停／停止控制。剪贴板写入、浏览器准备／上传／下载、页面脚本、录制、回放、安装、配置修改及文件输出另有具体调用授权；`install_ffmpeg` 使用终端命令能力审批。QQ 和自醒任务不继承本机桌面授权。全访问模式沿用现行权限策略。

窗口与进程引用由宿主管理，按 Eden 会话、回合和行动角色隔离。64 位 HWND 经 JSON 边界精确保留，不转换为有损 Number；内部快照由宿主补充，不作为模型参数。网页脚本结果、剪贴板正文和配置值按业务内容保留，不能递归删改其任意 ID 字段。公开 Cua 会话标签映射到私有 SDK 会话名，生命周期结果过滤其他实例的会话。

每个 SDK 客户端同时跟踪 worker 进程代际和原生会话代际。变化、暂停或停止使旧引用失效。释放范围会先取消并等待在途 FFI，再关闭 SDK；客户端断开会释放所属范围，超过 32 个上下文时清理该客户端空闲旧范围。正常关闭、取消无法完成及 broker 看门狗均会收掉 worker，不重放原生动作。普通操作预算 30 秒，下载 120 秒，回放与安装 300 秒；状态验证按参数受限扩展。

`confirmed`、`partial`、`unverifiable`、`suspected_noop` 和 `refused` 不合并成成功。送达、驱动直接验证和业务任务完成仍是不同事实，未知／取消结果应先观察。

## 六条审计缺陷的处理

| 原缺陷 | 当前处理与证据范围 |
| --- | --- |
| 文字输入忽略 x/y | 原样传入官方 `type_text`，不再经过 C# `Type()`；验证坐标与完整文本只派发一次 |
| 组合键忽略 element | 指定 token／快照传入官方 `hotkey` 或 `press_key`，不再执行旧焦点判断 |
| 长文本每 64 字继续派发到新焦点 | 删除 Eden 分块执行链；源码核对官方合成文字建立焦点后构造完整 SendInput 批次，宿主不自行拆分或重试 |
| UIA 根边界被拉伸到截图 | 保留原始物理 frame 和截图 scale；兼容路径发现系统／驱动窗口尺寸明显矛盾时标记几何未知，交集不伪报不可见，并阻止该控件输入 |
| 恢复后激活与观察死锁 | 移除必须先观察才能激活的恢复门槛，允许已发现窗口先激活后重新观察 |
| 已知标题不匹配却先输入 | 兼容文字和按键操作在派发前重新查询标题，不匹配直接阻止 |

以上包括宿主回归、参数契约与固定上游源码核对，不替代真实应用输入验收。原生截图路径交由 Cua 的 PrintWindow／WGC／屏幕区域回退等实现；不宣称所有应用的后台捕获都可用。
