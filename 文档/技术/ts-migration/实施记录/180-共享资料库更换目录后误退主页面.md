# 180：共享资料库更换目录后误退主页面

日期：2026-10-07。模块：AgentFrontend 共享资料库目录选择与请求作用域。

## 问题与修正

用户在共享资料库点击“更换工作区目录…”并选择文件夹后，页面返回主页面。`workspace.switch` 的回复与持久 `workspace.changed` 通知经不同连接投递，先后顺序不能保证。旧实现只在选择函数执行期间忽略通知；回复完成后立即清除 `pending`，而通知可能稍后到达，也可能落在 React 尚未安装新目录作用域的窗口。通知将客户端失效，触发 `onBack`。

- `SharedWorkspacePage` 的本页切换标识保持至新的状态所有者安装。取消、失败和返回仍结束本次选择，不恢复旧账号的迟到结果。
- `useSharedWorkspace` 仍按所属会话处理工作区事件，读取服务端的 `currentPath`（兼容 `path`）；已展示目录的迟到或重复通知不会使新作用域失效。其他目录或没有目录信息的本会话通知保持原有失效保护。
- 资料库选择保留；新目录重新选择并确认。选择文件夹不创建绑定、不自动扩大共享范围。后端目录切换仍通过原 RPC、实际规范路径和会话权限检查，不以本地路径冒充切换成功。
- 修正既有事件投影测试中过时的预期：投影会携带事件所属的 `sessionID`。新增规范路径保留及事件所属会话覆盖伪造 payload 会话的回归，生产投影逻辑未改变。
