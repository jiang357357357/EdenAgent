## 自动提取执行器与审批衔接

- 新增 MemoryExtractionRunner，串接来源账本、无工具模型提取、候选持久化、真实 PermissionService 审批和最终保存事务。
  默认同时执行 2 项，上限配置 1–8；同一任务共享正在运行的 Promise，超过并发数明确拒绝，由后续调度层负责排队。
- PermissionService 增加 requestWithId，返回已落盘并允许的审批 ID；原 request 的 Promise<void> 契约保持兼容。
  执行器把该 ID 交给保存事务校验，不从列表猜测或复用其他请求。候选先落盘再审批，完成任务重入不再请求模型。
- 拒绝审批保留 candidates，显式再次运行只申请新审批而不重新提取。close 拒绝新任务、取消模型及审批等待，并等待活动任务全部结束。
  模型执行中取消记 interrupted；普通提取失败记 failed；持久化失败与原异常一起保留。候选阶段取消不删除候选、不写入记忆。
- 模型解析接收取消信号，解析成功后才 claim：绑定未恢复保持 queued，可在模型恢复后重新调度。
  真实模型请求由注入的 record 持久化回调先保存；回调失败时没有 HTTP 请求。

## 有界提取队列驱动

- 新增 MemoryExtractionQueue，通过键集分页领取 queued 任务，默认 2 个活动槽位，完成后继续补位。
  同一活动任务在重复 wake 时去重；每次 wake 只扫描一遍，未恢复模型等失败任务保留 queued，等待后续明确唤醒，不形成自动重试循环。
- 每次扫描通过 setImmediate 让出事件循环，避免长队列连续微任务占用宿主；活动任务数受 1–8 的配置边界限制。
  每项失败交给注入的报告函数。队列读取或报告持久化异常停止驱动、保存故障并中止活动执行，close 再次报告故障。
- close 取消尚未执行的驱动回调、拒绝新唤醒、取消活动信号，同时等待执行器和活动任务结束后才返回；关闭报错也不跳过等待。
- 队列专项 **4/4 通过**；与执行器及真实 SQLite/录制模型/审批服务关闭联测联合 **11/11 通过**。
  实测审批等待时关闭：审批变 cancelled、候选保留、第二个来源仍 queued、仅发出一次模型请求且没有记忆写入。
  类型检查和工程门禁通过（232 个源文件、0 错误），日志 `/tmp/eden-extraction-queue-tests.log`。
- 本批未重跑全量宿主。该队列驱动已验证，完成回合事件订阅、漏触发恢复及生产容器生命周期接线仍待实施。

## 单会话后台取消

- 队列为每个活动任务保存来源 sessionId 和独立 AbortController；session.closed/session.deleted 事件只中止该会话的任务，不关闭整个队列。

## Mon 模型绑定持久化仓库

- 新增第 18 次数据库迁移及 ModelBindingRepository，为会话/默认绑定保存完整模型快照、当时 participants 和更新时间。
  快照支持单角色 main/vision，或多人 actors/main/vision/director；严格校验模型、角色 ID、重复 actor 和 512 KiB 上限。
- 仓库只允许 Mon 数据库；local 模型继续由 local 宿主配置提供。模型凭据保存在所属世界的私有 SQLite 中，不写入公开事件；沿用数据库 POSIX 0600 权限，不宣称额外的静态加密。
- 恢复要求会话仍 active、当前 participants 与保存名单一致；多人绑定还须与实际 assistant ID 集合匹配，不能恢复到单角色或错误名单。
  环境变化不使绑定失效，参与者变化、会话关闭或删除会阻止旧绑定恢复。
- 替换在单个事务中完成，持久化失败保留旧快照。专项 **3/3 通过**：磁盘重开、多类绑定、默认绑定、凭据不进事件、文件权限、名单/环境变化、关闭、回滚及大小/世界边界。

## ModelService 持久化适配

- ModelService 增加可选 ModelBindingRepository，构造时恢复有效绑定；主模型、视觉模型、actor 和导演绑定均先持久化，再整体安装内存状态。
  单角色替换清除旧视觉/actor/导演绑定；多人替换保存完整角色集合，避免保留上一组模型。
- 解析与公开状态读取时重新校验所属会话/名单，数据库无有效快照则清除缓存。调用者修改返回对象不能污染后续持久化解析结果。
  失效先删除记录再清理内存；若名单已变而删除失败，后续解析仍因名单不匹配拒绝旧模型。
