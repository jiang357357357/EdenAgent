# 184：共享资料库与当前工作区独立及读写技能

日期：2026-10-07。模块：Server 共享资料库、内置技能、API 与 AgentFrontend。

## 输入、状态与行为

用户要求共享资料库成为单独的新技能，可以读写；当前工作区仍是当前工作区。共享目录改为当前伊甸园账号私有的独立选择，保存在 `shared-workspace-lan/selected-directory.json`，包含账号标识、规范路径和选择修订号，不含登录凭据。不读取或修改 `session_workspaces`、默认工作区或工作区选择审计。会话 ID 只用于所有权校验、审批与读写快照作用域，同一账号的不同会话使用同一份共享选择。

新增 `sharedWorkspace.directory.read/select` RPC。目录选择要求有效绝对路径和预期修订号；旧选择的迟到提交被拒绝。首次没有选择时允许查资料库、发现和配对设备，文件操作仍要求有效目录及绑定。没有登记的共享绑定不会从项目目录猜测默认根。恢复多个已登记的同步引擎时仍固定其原目录；只有一个明确登记的旧绑定时可初始化独立选择，并保留旧绑定键。项目安装/默认目录改变不会搬迁或重定向共享目录；丢失目录单独报错并保留登记。

前端共享页面始终显示共享目录和选择入口，未有资料库、未选择项目或目录失效时也能重新选择。独立目录 RPC 取代 `switchWorkspace`。共享视图只监听共享目录及账号/世界事件；普通工作区切换不销毁共享视图。共享选择变化通知作用于整个账号，包括其他会话，迟到读取不能覆盖较新的选择。绑定仍要求明确确认，已绑定其他库仍要求另选目录，不隐式共享当前项目。管理协议中的旧字段 `expectedWorkspacePath` 兼容保留，其校验对象已改为独立共享目录；空字符串仅支持尚未选择目录时的账号级操作。

## 技能与文件边界

新增内置技能 `eden-shared-library`，通过项目既有 SKILL.md 快照目录发布，与 `eden-workspace` 分开。查询仍是单一 `query_shared_workspace`，保留 action=status/spaces/files；结果改为独立 directory/sharedDirectory，不再报告项目目录。新增 `read_shared_file`、`write_shared_file`、`edit_shared_file`，由常规工具发现/加载使用；尘世不注册这些共享工具。原工作区文件工具和工作区选择行为没有改动。

共享文件工具只接受库内相对路径，禁止绝对路径、上级跳转及符号链接越界。读写只解析当前独立共享根；未绑定时拒绝访问。文本写入最大 1 MiB，目录需已存在，编辑要求唯一 oldText 和完整 UTF-8 内容。写入前核对 owner/editor 角色，使用 `shared_workspace.write` 审批；审批后重新检查账号连接、会话、选择修订、角色和绑定。文件读取 SHA 快照按会话、回合与角色隔离，原子写入拒绝外部并发改动，禁止以旧读取覆盖新内容。选择先切走再切回也不能复用旧审批。

文件提交与共享绑定使用固定目录的同一变更队列，后台已绑定同步不追随项目或共享选择变更。复用工作区模块公开的路径读取和原子写入函数仅为文件 I/O 安全机制复用，不读取工作区选择。子任务只读角色可以读取共享文件，所有子任务继续禁止共享写入工具。工具写入成功仅表示本地提交；返回 synchronized=false，不能声称对端已收到。同步、暂停、冲突及历史操作继续使用既有页面与服务。
