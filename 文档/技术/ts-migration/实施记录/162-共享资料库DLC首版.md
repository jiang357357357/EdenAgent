# 共享资料库 DLC 首版

日期：2026-10-04。按用户“开始实现”要求，将 `DLC/SharedWorkspace` 从设计骨架实现为可选的共享资料库源码，保留现有各仓库未提交改动，不推进产品版本。

## 实现范围

- 中心是 Core 可选 Django app，复用 Core Token 认证，提供空间、成员、设备撤销、私有 Blob、文件版本、变更游标和幂等提交；数据留在中心本机。
- 本地引擎使用 Node 22 内置 SQLite 和不可变内容快照，离线队列可跨退出恢复；冲突保留双方内容，恢复历史写出新版本，不回退版本号。
- Agent 的身份来自已验证 WebSocket 连接，令牌只在内存使用。账号断开时取消传输、停止扫描，按账号隔离设备身份和同步数据库。
- `packages/api` 定义全部 RPC，前端使用生成客户端。界面明确选择完整当前工作区并勾选后才绑定，创建资料库不会自动共享；成员管理及设备撤销经过真实中心接口。
- 源码 DLC 路径为工作区 `DLC/SharedWorkspace`；便携设计为主工作区同级 `SharedWorkspace`。加载以工作区锚点和当前启用状态为准，不写死开发机器绝对路径。

本轮主代理审阅并允许一处动态导入：`Server/src/modules/shared-workspace/loader.ts`。它仅导入重新验证后的固定本地 `client/index.ts`，路径由可信安装清单和显式启用状态决定，不能由模型或 RPC 指定；架构例外仅精确匹配此文件。

## 数据保护与边界

文件先生成稳定快照并校验 SHA-256，服务端在同一事务中比较基础版本、写版本和操作回执；丢失响应可以重复提交。下载在替换前再次检查本地内容和工作区范围；已经变化的文件进入冲突。已替换但元数据未落盘的中断可以恢复，不把远端内容重复上传成新版本。

原始文件在替换前保存在工作区 `.eden-shared-backups`，同名 UUID JSON 记录相对路径、哈希和时间，供人工恢复。首版没有备份浏览器或自动清理。无歧义且内容不变的重命名保留文件身份；同时修改内容或来源不唯一的重命名可能体现为删除与新增。

本轮回归覆盖：重命名目标内容恰好匹配远端但旧源已被编辑时仍保留冲突；下载在途或恢复历史等待同步期间切换工作区时，拒绝继续写文件。

每 10 秒扫描活动工作区，面板每 5 秒查询状态，不使用文件 watcher。单文件上限 16 MiB；数据库、环境密钥和同步缓存被排除。仅同步用户明确绑定的文件目录，不同步角色记忆、账号库、API Key 或模型配置，不提供 RAG、语义检索或实时多人编辑。权限撤销不远程删除已有本地副本。服务重连后重试，不保证离线仍能调用云模型。
