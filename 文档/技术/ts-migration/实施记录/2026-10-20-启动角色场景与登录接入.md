# 2026-10-20 启动角色场景与登录接入

> 10-21 用户指出出场效果不符合参考项目后，已替换本记录中的 CSS 出场与固定布局实现。当前实现和验收以[按 ShittimLogon 还原角色出场](2026-10-21-按ShittimLogon还原角色出场.md)为准，下面保留首轮接入的历史记录。

按用户“先开始接入到我们智能体前端，刚开始启动的时候，点击角色，返回的时候，弹出登录组件”，将本地 ShittimLogon 角色场景接入 Eden Agent 主窗口的启动入口。启动显示教室，点击角色后播放回应，再让角色出现在前景并弹出登录框；关闭登录框或按 Esc 返回教室，可以再次点击。白天（06:00–17:59）为阿罗娜，夜间为普拉娜，按本次启动的本地时间选定。

## 实现与状态归属

- `frontend/web/src/App.tsx` 持有本次主窗口的入口完成状态，完成后进入既有页面。设置、问题及角色辅助窗口沿用原来的认证与入口。入口期间保持登录窗口尺寸，完成且已认证后恢复主界面尺寸。
- `pages/startup/StartupEntrance.tsx` 持有 `room → reacting → entering → login` 状态。教室回应等待真实 Spine track 3 的 complete 事件；前景角色加载后等待 350ms 显示登录框。点击直接登录／跳过动画可继续；过渡阶段 8 秒兜底，教室资源加载 12 秒兜底。
- `room-renderer.ts` 复用现有 Spine 加载器与 Pixi 7，使用原素材的 `Idle_background_00`、`Idle_02`、`Idle_02_Touch_A/M`。角色点击区域来自可见角色骨骼的世界坐标边界，竖屏会平移镜头保持角色可见。前景显示时隐藏教室中的角色槽位，背景虚化；返回时恢复骨骼、轨道与点击区域。
- `StartupLoginPanel.tsx` 使用抽出的 `pages/login/LoginForm.tsx`，登录仍调用 App 的 `handleLogin → loginWithCore`。已有效认证的账号显示继续入口；尘世保留独立入口。提交中禁用返回及世界切换，错误保留在登录框，焦点限制在弹窗内。
- 返回会取消阶段定时器并销毁前景渲染器；离开入口时释放教室的纹理、Atlas、Pixi、监听器及 ResizeObserver。场景加载、WebGL 或懒加载失败时继续显示登录组件。隐藏文档暂停教室 ticker。
- `StartupSceneControls.tsx` 负责顶部标识、场景准备提示、直接登录和跳过按钮；场景渲染与认证分别由对应模块负责。没有新增后端协议、角色配置或运行权限开关。

本轮接入教室点击回应与前景角色。前景使用既有角色渲染器，作为登录背景展示；语音、字幕、前景摸头互动及 6 秒启动视频不在本轮实现中。
