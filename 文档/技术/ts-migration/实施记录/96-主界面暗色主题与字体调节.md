# 主界面暗色主题与字体调节

日期：2026-09-17。

## 实现

- 主界面改为接近 VS Code Dark Modern 的深炭灰配色：背景 `#181818`、卡片 `#252526`、低对比边框 `#454545`、正文 `#d4d4d4`，交互强调色改为蓝色 `#3794ff`。
- 背景图片继续覆盖整个窗口，在图片上增加半透明黑色压暗层；左侧导航与会话栏使用半透明深色面板和毛玻璃，不恢复此前删除的白色罩层。
- 顶部工具栏使用一个“外观”按钮统一承载字体和背景设置。下拉面板支持 80%–140% 字体缩放、背景透明度、毛玻璃、图片切换及恢复默认；字体与背景仍由独立偏好数据持久化。
- 普通 `rem` 字体随根字号同步变化；聊天区历史使用 `vh` 固定字号的元素额外使用统一像素增量，覆盖会话列表、消息、工具记录及输入区域，同时不改变布局尺寸。
- 字体设置通过独立的 `ui.appearance.get/update` RPC 保存，和背景图片、背景透明度、自动滚动解耦。
- 设置写入当前世界/账号的 `runtime_settings`，切换账号或世界后读取各自的值；异常值回退为 100%。
