# 右侧立绘顶部空白

日期：2026-10-06。模块：智能体 Web 前端角色面板。

## 原因与修复

`CharacterPanel` 对普通立绘使用 `absolute inset-x-0 bottom-0 flex h-[96vh]`，容器贴底且只有窗口高度的 96%，上方留下固定的 4vh。用户截图中立绘上缘被水平裁切、上方出现背景空带，与该舞台边界一致。

将舞台统一改为 `absolute inset-0 flex justify-center`，铺满右侧面板。删除不再使用的回忆大厅分支判断；保留用户已保存的缩放、平移、动作和渲染器适配行为。
