# 2026-10-23 桌面控制小窗取消自动弹出

用户再次反馈每次桌面调用仍弹出带暂停、恢复、停止按钮的小窗，并提供“桌面控制就绪”截图。上一版只保持步骤间的窗口状态，仍会在新活动时自动显示，没有覆盖用户关闭后继续调用的场景。本轮取消所有状态驱动的自动显示。

## 最终行为

- 浮窗仅由托盘“桌面控制”的显式操作打开。工具调用、空闲、暂停、停止、连接变化和账号状态刷新只更新状态，均不创建或显示浮窗。
- 已手动打开的窗口保持显示；关闭后继续调用任一世界的桌面工具也不会重新显示。再次从托盘打开时重用同一个窗口。
- 保留操作中关闭先停止、停止失败保持窗口及错误、账号切换清理旧标题、IPC 来源校验和不抢焦点显示规则。全局停止快捷键和桌面审批未改动。

生产变更仅位于 `frontend/desktop/src/desktop-control/control-service.cjs`：删除自动显示及按 busy 重置关闭状态的分支，窗口创建入口仅由 `manual` 控制。已检查主进程 `desktopControl.show()` 的调用来源为托盘菜单。

共 29 项不同测试通过，0 失败、0 跳过；生产服务 `node --check` 通过。覆盖启动时有活动也不创建窗口、关闭后两个世界继续多次调用仍隐藏、暂停／停止／断连／恢复不自动显示、手动打开和托盘重开、失败停止及账号隔离。真实 Electron 测试在首次手动打开前断言窗口数为零，关闭后执行三轮运行／空闲，确认原生显示调用次数不增加，托盘重开只增加一次显示。

## 生效

本轮未重启现有客户端或服务。需从托盘完全退出并重新启动桌面客户端，以加载新的 Electron 主进程；刷新聊天页面无法加载此变更。CommonJS 服务按原路径随桌面源码资源分发，无额外 Server 或 Web 构建变更。
