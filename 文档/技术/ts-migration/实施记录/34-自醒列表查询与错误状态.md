# 自醒列表查询与错误状态

2026-09-10，用户截图显示近期自醒 `incomplete input`、下次醒来读取失败，而正文提示等待第一次自醒。

## 原因与修复

- Server self-awake repository 的列表 SQL 搜索条件缺少外层右括号，SQLite 在 COUNT 查询即失败，同一接口返回的调度信息也无法读取。补齐括号并明确决策搜索的 `instr(...)>0` 条件。
- 前端概览与日记正文区区分初次加载、请求失败和空记录；概览搜索无结果单独提示，不再将失败或过滤结果当成从未自醒。
- 保持现有刷新入口、分页、调度和数据库内容；不触发自醒或修改真实用户数据库。
