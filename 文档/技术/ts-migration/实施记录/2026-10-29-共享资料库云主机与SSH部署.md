# 2026-10-29 共享资料库云主机与 SSH 部署

## 范围与归属

用户要求任一已启用 DLC 的子机可以部署云主机，支持按 IP 连接，也支持某台子机作为主机；用户选择在子机填写 SSH 信息直接部署。

`packages/shared-workspace/lan` 统一主机身份、配对、认证加密、权威版本和设备权限。普通子机保留局域网来源限制，显式主机连接允许公网 IPv4、域名及 HTTPS。`host/` 是无桌面、无 Core 的 Linux 运行入口，部署只登记管理员 UUID 与公钥，数据独立持久化，不回连 NAT 后的子机。

`Server/modules/shared-workspace` 协调 SSH 指纹预探测、密码 / 私钥认证、内存部署任务、上传校验、独立 MonPM 配置、自动管理员配对和按主机管理。部署任务与 LAN 身份同属本机账号，账号退出取消在途操作；SSH 凭据不入任务快照或磁盘，口令纳入统一脱敏。重复部署核对原管理员，备份旧程序，保留数据，拒绝其他程序目录。取消或连接中断后明确要求核对远端状态。

API 是唯一 RPC schema 来源；前端「主机与配对」接入 SSH 表单、信任确认、进度和地址连接，新建资料库选择本机 / 云端。网络管理读取所选主机设备，成员授权读取绑定库所属主机设备，丢弃跨账号、目录和过期部署状态。Server 打包包含独立主机 / 安装模板及 `ssh2@1.17.0` 依赖。

## 边界与待验收

云端当前需预装 Node.js 22.23.1+ 和支持 schema / IPC 2 的 MonPM，不提供系统依赖自动安装；SSH 自动部署默认 HTTP，TLS 入口及反向代理可单独配置。开机服务通过 MonPM Linux 用户服务安装，用户总线 / linger 权限不足时显示降级结果，不能宣称系统重启恢复已验收。

真实云服务器地址与 SSH 账号尚未提供。真实公网 SSH、安全组、防火墙、证书、系统开机服务、物理双机及长时间运行待现场验收。未改动真实用户资料、已安装客户端、Mon 正式版本或客户归档，不调用 GitCode 分发。
