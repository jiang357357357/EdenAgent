## 当前页面

`SharedWorkspaceNavigation` 只包含资料库、设备配对、同步状态、冲突处理、文件历史、共享权限六项。导航属于共享页面自身，当前子功能强调显示；宽窗口左侧纵排，窄窗口顶部横排。资料库页保留搜索、行内创建、选择和目录绑定，设备页包含 LAN 发现、邀请配对与已配对设备管理；同步、冲突、历史、权限各有独立内容，原底部页签移至这份导航，不再有重复页签。

`SharedWorkspacePageView` 持有子功能和资料库选择；隐藏面板保留挂载与各自滚动，切换不清空创建草稿、配对输入或目录确认，也不自动调用绑定、配对、同步、恢复或权限写操作。选目录后保持所在共享页面和库，新目录依照既有作用域与组件 key 重置确认。长错误/状态提示在受限区域滚动，不挤掉内容区。

`SharedWorkspacePanel` 使用现有状态所有者与服务端真实结果。设备入口不要求已有库或本机发布 DLC；管理功能要求所选库 ID 与实际绑定库 ID 相同，否则提示先进入资料库选择或绑定。不会展示另一库的同步、历史、冲突或授权操作。原服务端目录与角色权限校验、客户端过期结果保护继续生效，未修改协议、身份、库数据或本机文件。
