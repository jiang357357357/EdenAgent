# 会话账号隔离与历史归属恢复

日期：2026-09-16。

后续：本记录描述初始行级隔离；2026-09-17 已升级为账号独立数据库与完整业务实例，RPC 不再依赖通用结果过滤。当前边界见 [实施记录 92](92-伊甸园账号独立存储与业务运行实例.md)。

## 问题

Mon 登录原来只控制 Core 访问；Agent RPC 仅认证世界实例能力令牌。会话表没有账号归属，列表、直接读取、事件广播均可跨登录账号访问。退出前端不能解决后端权限缺失。

## 实现

- 新增 accounts 业务模块。Mon RPC 初始化必须提交 Core 登录凭据，由宿主向配置的 Core `/api/users/me/profile/` 验证，身份键由 Core 地址与用户 ID 组成；不接受客户端指定归属。连接定期复核，切换身份须重新连接。普通 RPC 中的 Core 凭据和地址不得替换成其他账号或服务。
- `session_owners` 独立持久化会话归属；创建在同一事务写入，子会话继承父会话，签名自醒绑定已校验的服务用户。列表在 SQL 分页前过滤，直接访问和写操作校验归属。
- RPC 入口校验会话 ID 和持久资源引用，覆盖通过任务、审批、媒体、执行记录等 ID 间接访问会话。列表结果补充过滤；任务、自醒、连接器操作等分页查询按账号过滤。WebSocket 只推送所属账号的事件。
- Blob HTTP 增加 Core 认证；上传授予当前账号访问权，内容去重不授予其他账号访问权；历史附件通过所属会话持久引用读取。实时语音在升级连接前校验账号与会话归属。
- 记忆、备忘、通知及自动滚动偏好补充账号归属。角色相同不意味着可共享另一账号的记忆。自动记忆提取按来源会话保存归属和去重。
- 请求作用域使用 AsyncLocalStorage；后台事件订阅不继承触发者的浏览器身份，智能体执行按目标会话恢复账号作用域。无法确认归属的 Mon 会话暂停执行。
- 登录、退出及其他窗口切换账号时，清空前端会话状态、关闭旧连接并使未完成请求失效。新连接重新认证；附件缓存、上传和语音连接跟随账号变化失效。

状态所有者：Core 验证账号身份；Agent 数据库保存会话及业务记录归属；浏览器只保存登录凭据并展示结果。未验证、越权或归属未知均拒绝访问，不自动认领历史会话。

本次隔离范围是 Agent 协议中的会话及关联业务记录；本机工具、工作区和宿主配置仍遵循现有共享 OS 账户及沙箱暂停策略，不构成操作系统文件隔离。

## 历史恢复

仅使用已验证的历史 Core 凭据，或签名自醒提交与已知服务用户的对应关系恢复归属，再传播至子会话、来源记忆和备忘。不会相信环境快照中自报的 userId。验证并发最多 4，整个网络恢复窗口最多 5 秒；凭据失效或 Core 不可用时保留未分配状态。

本机正常升级后：47 个会话中 20 个恢复归属，27 个仍未确认并隐藏。未删除会话或消息，未将未知历史分配给当前登录账号。
