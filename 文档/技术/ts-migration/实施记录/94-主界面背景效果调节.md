# 主界面背景效果调节

日期：2026-09-17。

## 实现

- 聊天页顶部右侧工具栏新增背景图片图标，点击显示小型下拉面板。
- 面板可实时调节背景透明度（0–100%）和毛玻璃模糊（0–30px），并可恢复原图。
- 面板支持从本机选择 JPEG、PNG、WebP、GIF 或 AVIF 图片（最大 20 MB），也可随时切回随包默认图片；重置背景效果不会替换当前图片。
- 背景图片独立渲染在角色、消息和控件下方，透明度及模糊不会作用于前景内容。模糊层向窗口外扩展，避免边缘出现空白。
- 左侧活动导航与会话列表移除固定底色，使用同一背景层，因此透明度和毛玻璃参数覆盖整个窗口宽度。
- 滑块立即更新画面，并在停止调节 180ms 后保存，减少连续拖动造成的 RPC 请求。
- 设置写入当前运行世界的账号数据库。伊甸园账号实例、尘世实例分别保存；切换账号后重新读取。
- 自定义图片写入当前账号的 Blob 存储，偏好只保存 Blob ID。显示时通过带账号认证的 Blob 请求生成临时 URL，不保存本机绝对路径。后端拒绝非图片 Blob、其他账号的 Blob 和不存在的 Blob。
- 存储值经过 RPC schema 和仓储读取校验，异常数据回退为透明度 100%、模糊 0px 的原图状态。
