# 128 写日记工具与自动保存衔接

2026-09-21，按用户要求增加真正的 `write_diary` 工具。

- 工具默认直接提供给自醒角色，接受必填正文 `content` 和可选标题 `title`，保存后返回日记 ID、标题及保存时间。
- 写入经过 `memory.write` 权限请求，绑定当前会话与回合，并核对账号归属及运行状态。重复调用更新本篇，不生成重复日记。
- 保存不结束自醒，可以继续设置时钟；完成回合时保留工具已保存的正文，允许最终回复为空。没有调用工具的旧路径仍保留最终正文自动保存。
- 自醒主提示与技能正文统一为“用 write_diary 写日记。用 set_self_awake_timer 设置下次醒来的时间。”

验证：15 项日记、时钟、提示词相关测试通过，使用内存数据库；服务端类型检查及差异空白检查通过。测试覆盖权限拒绝、跨账号/回合拒绝、重复写入、完成后拒绝写入，以及最终确认语或空回复不覆盖日记。原时钟测试改为按工具名称定位。
