# 开场经文与动画细化

按用户要求继续美化开场动画，并将字幕替换为 README 中的圣经和合本节选：**我要在那里与你相会。**（《出埃及记》25:22）。文案在开场组件中展示，测试直接读取 README 原句进行核对。

沿用 image-to-code 工作流，使用内置 image_gen 生成更新后的单幅参考，分析后实现：精细点状外轨、逐段描出的光弧、倾斜椭圆内轨、三个星芒、斜向光带和细微水面倒影。参考图与完整生成提示词位于 `.artifacts/startup-opening-scripture-20261021/design-reference.png` 和 `design.json`。运行时仍使用 CSS/SVG，位图只用于设计记录；云层与摄影式水面简化为渐变和线条。

上一版复用了会被浅色主题覆盖的 `--color-info`，导致奶油等主题下的开场光效偏暗。此次在 `theme.css` 集中定义开场天空、海面和光晕的三个语义颜色，其值不随明暗主题改变。没有改动现有全局信息色或其他界面配色。

字幕采用 16–20px 中文宋体回退栈、适度字距和可收缩宽度。正常播放最低时长由 1.4 秒调为约 2.4 秒，淡出由 0.65 秒调为 0.8 秒，让经文有完整显示时间。主体轨道与字幕分别退场，背景同步淡出；仍等原生高清场景准备好后揭开，支持跳过和减少动态效果。登录与失败回退状态归属继续保持在原有场景状态机中，未接入新的网络或业务服务。

实现涉及 `StartupOpening.tsx`、新增的 `StartupOpeningEmblem.tsx`、`StartupOpeningArt.tsx`、`startup-opening.css`、`useStartupOpening.ts` 和 `theme.css`。SVG 图形独立成组件，渐变使用 React `useId` 避免引用冲突；背景与图形均没有新增依赖或运行时位图。

使用 Node 22.23.1 执行 Web `tsc --noEmit`、主题检查、Vite 构建与本轮证据目录的 `check-source.mjs`，全部通过。主题检查 317 文件；启动源码 26 模块，零错误、零提醒；构建保留既有大体积 chunk 提示。
