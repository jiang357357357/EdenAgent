# 回答末尾耗时与历史恢复

日期：2026-10-05。模块：Agent Web 消息渲染、会话事件投影与输入完成事件。

## 行为与状态归属

- 回答末尾、原始输出按钮之后显示时钟图标和“耗时”，按秒、分钟或小时格式化；计时不写入回答正文、原始输出或语音内容。
- 起点为持久 `turn.started.created_at`，终点为 `turn.completed.created_at`，包含思考、工具、审批等待、多角色规划与运行时收尾，不包含排队等待。
- 按会话和 turn ID 关联；同一轮的工具过程、多段消息及多个角色只在最后一条可见 assistant 消息后显示一次。下一轮运行不影响上一轮耗时。
- Server 的 `message-turn-timing.ts` 在 `message.list` 返回时派生 `payload.turnTiming`，每个当前分页涉及的回合至多两次复合索引端点查询，不扫描流式正文，不改写已有消息或数据库 schema。
- 正常完成事件携带从同会话、同回合首个开始事件读取的 `turnTiming.startedAt`，解决第一条完整回复尚未落库时重新打开页面、错过开始事件的情况。
- Web 保留消息历史时间和实时回合时间，selector 聚合同轮所有已加载历史消息，再合并实时边界。不用模型消息自身的时间戳猜测总耗时。
- 缺少边界、负时差、非法数值、运行中、失败或取消不伪造成功回答耗时。旧服务仍兼容实时开始/结束事件，完整历史恢复需新服务投影。
