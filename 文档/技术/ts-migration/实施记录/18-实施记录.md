## Windows 本机终端执行（已编写，未运行）

- 阅读发现 CommandService 在用户明确选择 host 后仍对 win32 一概拒绝；工具说明也写死 /bin/sh。新增 host-command 与 windows-process，接入原宿主审批/执行快照/活动命令锁。
- Windows 使用固定 SystemRoot 下的 Windows PowerShell 与 taskkill，缺任一可执行文件时报告不可用；NoProfile/NonInteractive、UTF-16LE EncodedCommand 避免额外命令行引用，输出显式 UTF-8。
- 子进程只传 SystemRoot/WINDIR、系统 PATH、TEMP/TMP，不继承整份含模型凭据的宿主环境。工具路径未加入系统 PATH 时应使用绝对路径。
- 超时/取消/超出输出上限调用 taskkill /PID /T /F，等待终止结果；未确认终止返回明确错误，不把仅杀主进程报告成整树成功。终止过程额外最多等待 10 秒。此为本机执行收尾，不是 Windows 沙箱或 Job Object 隔离。
- 默认仍为 sandbox。Windows OS 沙箱未实现时继续不可用，不因本机执行支持而自动降级；MCP stdio、技能/插件代码仍保持原沙箱要求。
- 本轮实际 grep/ls/cat 读取源码和 shell/Python 文本编辑，未执行 PowerShell、taskkill、能力探测、构建、类型检查或测试。
- 待集中验收：Windows 输出编码、错误退出、子进程树、超时/取消竞态、缺失系统工具与沙箱模式拒绝。跨平台沙箱和原生隔离仍未完成。
