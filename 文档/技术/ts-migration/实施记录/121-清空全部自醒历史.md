# 121 清空全部自醒历史

2026-09-20，用户确认日记正文之外也要删除自醒执行历史，批准实施。

## 实现及边界

- 新增严格要求 confirmClear=true 的 self_awake.history.clear，按当前认证账号及世界清理全部分页、全部角色的自醒历史。
- 同一事务按外键依赖顺序删除通知复核、执行复核、通知历史、日记及 self_awake_runs。正在处理的自醒阻止清理并明确提示，避免删除运行中的状态。旧的仅清日记 RPC 保持兼容。
- 页面按钮与确认文案改为“清空自醒历史”，成功后清空缓存、选择和分页，重新加载空列表；旧记录的 execution 查询变为不存在。
- 保留当前唤醒计划及会话。共享会话底层事件、模型上下文、作业幂等登记和既有备份不属于自醒列表记录的安全擦除；本次没有删除整个会话，避免破坏会话事件序号、上下文及其他会话功能。

## 实际清理

通过正式 Repository 和 withAccount 执行用户已授权的清理，当前账号库删除 42 条自醒执行记录，旧 mon 根库删除 23 条。清理前无运行中输入，清理前后调度结果一致。重启后只读复核当前账号、旧 mon 库及 local 库的自醒记录与日记均为 0。

最初管理脚本在 Repository 事务外又嵌套事务，被数据库拒绝且回滚；移除重复事务后按上述范围执行成功，没有扩大删除范围。

## 验证

- 5 项相关内存库测试通过，扩展覆盖运行中拒绝清理、账号隔离、全部历史删除、关联复核删除、空列表、旧详情不可查询、重复清理及新日记正常保存。
- RPC 生成、Server 类型检查、Web 主题检查/类型编译/生产构建通过，构建有既有大 bundle 提示；三个仓库 diff 空白检查通过。
- 等待输入空闲后重启开发宿主加载新 RPC 与前端；未额外触发自醒，未进行可视 UI 点击验收。
