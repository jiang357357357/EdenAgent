# 78 基础技能目录与工具彻底解耦

日期：2026-09-14。用户要求基础技能的名称与概要直接进入目录，并防止说明、目录与工具互相重复和影响。

## 实现

新增四份内置说明：eden-memory、eden-reminders、eden-workspace、eden-self-awake。每份只负责一种流程，正文集中于 Server/src/model-prompts/builtin-skills.ts，适配模块将其转换为标准 SkillSnapshot 与 SKILL.md。基础技能随独立 Server 制品分发，无需部署时写入 installed_skills 或扫描其他智能体目录。

bootstrap 显式提供内置技能来源，Repository 按已有优先级合并，管理员系统目录高于内置版本。同名技能只出现一次；启用状态由当前世界数据库保存。普通聊天、子任务、自醒按各自 profiles 提供摘要；全文按需读取。技能说明不复制工具参数 schema，工具描述不重复整套工作流，宿主指引只介绍发现与读取协议。

取消 load_skill 的工具自动加载副作用。其返回的 tools 是关联元数据，loaded 表示当前接口是否已暴露；执行资格只由独立工具注册、工具选择与权限策略决定。读取或重读技能不恢复已卸载工具；卸载技能不撤销已加载工具。角色技能预加载也不自动加载工具。技能与工具选择各自最多 96 项，不互占容量。旧版已保存的独立工具选择继续保留，不批量撤销历史选择，无 schema 变化。
