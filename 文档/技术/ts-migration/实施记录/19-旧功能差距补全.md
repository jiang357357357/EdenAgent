## 状态和失败处理

- 每个目录类别由 SystemSkillCatalog 单独拥有不可变内容快照；扫描完整成功才替换该类别。系统目录与工作区目录可独立成功或失败，失败类别保留同根目录上次有效内容，错误由 skill.catalog_status 和页面展示。关闭服务取消扫描并等待操作结束。
- 工作区根集合变化后，即使新目录尚未扫描成功，也不返回上一个工作区的技能。根目录重定向、包链接、重名、文件数量/内容超限均拒绝当前扫描。
- 主会话、子任务和多角色统一通过 runtime-pi 的 refreshTools 回调在公开 AgentHarness toolContext 边界更新；setTools 显式传入新的活动工具名称。系统提示仅加入最多 96 条技能发现元数据，完整目录通过 list_skills 获取，正文经 load_skill/read_skill 读取。代码不在 Server 导入 pi。
- 工具执行仍在请求审批后重读版本；运行中目录变化不替换已审批快照或赋予新权限。直接工具名绑定原内容摘要与工作区，子任务工具白名单继续生效，无法构造目录时明确失败。
- External 原样传递 argv、cwd 与 stdin，不通过拼接 Shell 执行技能/MCP。只交付临时校验快照，不直接交付可变来源目录或继承业务凭据环境。技能沿用超时和输出上限；MCP 沿用初始化/生命周期和 stderr 上限，Windows 补进程树关闭。External 的实际 OS、网络和资源限制仍由管理员提供的适配器实施；启动探测不是安全性证明。
- skill.refresh 属于显式扫描，不进入迁移审阅模式允许列表；只读 skill.catalog_status 可在审阅模式读取。未新增真实 Data 操作。
