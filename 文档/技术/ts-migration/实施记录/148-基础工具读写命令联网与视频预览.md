# 148 基础工具读写、命令、联网与视频预览

日期：2026-09-26

## 实施

- 公网 HTTP 地址校验先剥离 IPv6 URL 主机方括号，并拒绝 IPv4 映射 IPv6 地址，避免十六进制映射地址绕过私网判定。
- `read_file` 增加字节偏移与长度分页，明确返回 `nextOffset`；UTF-8 页边界不拆开字符。新增分页 `list_directory`、限定文件/目录数量及运行时间的 `search_files`，默认直接对当前工作区可用。
- 新增 `edit_file`，要求 `oldText` 恰好匹配一次，再以原文件哈希、现有写文件权限审批及原子写入提交；并发修改拒绝覆盖。整文件 `write_file` 仍保留。
- `exec_command` 可按调用设置 1–600 秒超时；超过 1 MiB 的输出仅截断返回，命令继续运行到完成或超时。终端选择及现有审批、取消和进程树终止链路沿用。
- 网页搜索/读取引用写入当前世界会话数据库，新迁移增加 `web_resources` 表；同会话最多保留最近 128 个引用，后端重启后可继续按 `refId` 读取。旧的内存引用没有可迁移来源。
- `read_attachment` 增加 `frames` 操作。经本机命令审批后，视频在设备安装 FFmpeg 时最多抽取前三张、约 0/5/10 秒画面给模型；临时文件清理。该预览不解析音轨，也不代表完整视频理解；缺少 FFmpeg 时明确提示。

## 边界与待验收

- 已完成 Server TypeScript 类型检查、Server 构建与差异空白检查；依业务优先约束，本轮未运行自动化、媒体实播或 UI 测试。
- `exec_command` 仍为单次等待模式，最长十分钟；尚无 Codex 式可轮询的长期进程会话。视频预览依赖目标设备 PATH 中的 FFmpeg，Windows 安装资源尚未捆绑该程序。
- 新数据库迁移要求旧安装版更新后再读取已升级的库。未操作真实用户数据库，也未更新 Windows 已安装运行包。
