# 共享模式单按钮自锁开关

日期：2026-10-30。正式版本仍为 1.11.7。

按老师要求，`SharedWorkspaceModeSwitch` 将两个互斥按钮合并为一个 `role="switch"` 按钮，OFF 为局域网共享，ON 为云主机共享。使用固定无障碍名称“云主机共享”和 `aria-checked` 表示开关，图标与可见模式文字随状态变化，支持鼠标、空格和回车；滑块使用主题语义颜色，并遵循减少动态效果的设置。

切换沿用 `owner.selectPosture` 与既有 RPC，等待后端确认后更新显示；切换、部署或读取模式时禁用，失败保留后端原模式。刷新恢复已保存的模式，两种目录继续独立记录，不新增本地替代状态或修改后端协议。

验证：相关 Node 回归 58 项、真实 Edge 浏览器 11 项通过，覆盖键盘与鼠标切换、刷新记忆、各自目录恢复、模式隔离、SSH 凭据清理和 390px 窄屏。Web 类型检查、主题 346 文件检查及隔离生产构建通过；构建保留现有大 chunk 提醒。已查看开关 ON/OFF 及实际资料库流程截图。

首次并发浏览器验收未完成，已核对命令行并只终止 3 个该轮临时测试 Node 进程；随后将浏览器夹具的 Vite 缓存放入各测试进程的隔离目录，串行完成全部 11 项，0 失败、0 跳过。测试采用隔离夹具，不访问真实用户数据库、云主机或真实共享目录。

当前开发 Vite 已提供新的 switch 代码，两个 Agent `/healthz` 均正常；本轮未重启服务、修改正式版本、更新客户程序或推送代码。证据与隔离构建位于根 `.release/shared-mode-toggle-20261030/`。
