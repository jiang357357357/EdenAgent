# 托盘唤起时重播开场

按用户要求，处于待机或登录界面时，每次主窗口从隐藏或最小化状态重新出现，都从头播放现有经文开场，结束后回到原页面。已显示的窗口再次点击托盘或普通焦点切换不触发重播；进入工作界面后移除重播监听。浏览器预览和旧桌面壳缺少新事件时保留既有显示行为。

此前 `StartupEntrance` 的开场状态只在组件首次挂载时初始化，托盘入口仅调用 `BrowserWindow.show()`，因此隐藏后再次显示不会重播。此次新增 `main-window-visibility.cjs`，仅挂接主窗口的 `show`、`hide`、`minimize`、`restore`，根据实际原生状态合并重复事件；订阅时提供当前状态，并校验发件窗口及主 frame。关闭或销毁时清理监听。托盘图标和“显示主窗口”菜单共用恢复、显示和聚焦处理，补齐最小化恢复。

`preload.cjs` 通过受限的 `onMainWindowVisibility` 桥发送布尔状态。前端 `useStartupOpeningReplay` 管理开场可见性和播放序号：隐藏时准备新遮罩、重新挂载开场装饰并暂停 CSS 与计时；重新显示时才开始完整播放。完成回调检查播放序号与当前可见性，避免旧计时结束新动画。原生高清场景仍就绪后才允许揭开，保留跳过和减少动态效果。

场景 Canvas、角色动作、运行模式与登录组件继续保留，隐藏和重播不通过刷新页面或卸载表单实现。开场期间底层继续使用 `inert`／`aria-hidden`，Escape 不改变背后的登录状态；结束后恢复原有焦点处理。独立设置、桌宠和问题窗口不订阅主窗口重播事件，也不能用其订阅请求触发主窗口状态外发。未新增认证、模型请求或工具执行。

实现涉及 Desktop 的 `main.cjs`、`preload.cjs`、`windows/main-window-visibility.cjs` 和 `windows/tray-controller.cjs`；Web 的 `desktop.d.ts`、`StartupEntrance.tsx`、`StartupOpening.tsx`、`useStartupOpening.ts`、`useStartupOpeningReplay.ts`、`startup-opening.css` 和独立的 `LoginPage.tsx`。独立登录页覆盖已经进入后账号失效的入口，复用同一重播 hook；首次挂载保持原有直接显示表单行为，托盘重开时加上开场。
