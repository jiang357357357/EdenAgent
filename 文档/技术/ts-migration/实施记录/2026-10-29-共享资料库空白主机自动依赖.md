# 2026-10-29 共享资料库空白主机自动依赖

用户要求即便远端为空白主机，子机填写 SSH 信息后也能完成部署。本节接续同日云主机记录，替代此前要求远端预装 Node/MonPM 的限制。

## 实现

- 完整 SharedWorkspace DLC 携带固定 Node.js 22.23.1、当前 Process 源码构建的静态 MonPM，以及私有 libstdc++/libgcc，分别提供 Linux x64/ARM64 资源和完整许可证。清单 schema 2 记录压缩/原始 SHA-256、大小、源码提交、源码指纹和构建器；MonPM componentVersion 读取现有根 VERSION，没有推进产品版本。
- Server 经固定 uname 检测架构，解压前后校验，SFTP 上传并回读校验后执行临时 Node 引导程序。仅在系统 C++ 库不可用时设置私有库路径，不替换全局运行时。云端不需下载、解压、Go 或 Python 工具。
- 安装器使用不可变 runtime/内容ID，检查目录、文件与管理员身份；备份程序/配置并保留 data。重部署重启自身配置对应的 MonPM，保留资料库、配对及版本。root/systemd 安装独立系统服务，普通用户尝试用户服务；无可用服务管理器时明确报告未注册开机服务。
- 公共 API 与前端统一自动准备依赖，删除 Node/MonPM 命令路径输入。完整 DLC 组装必须通过 SHA-256、ELF 类型及架构校验；Runtime 二进制被 Git 忽略，普通推送不触发编译或发布。

## 验证

共 150 项不同测试通过、0 跳过：Server/package 90，前端共享模块 55，运行包语义校验 3，真实 SSH/SFTP 空白 Linux 1，Chrome 交互 1。Server/Web 类型、主题、1364 个 TS 源码的架构检查及 Server/Web 生产构建通过。Vite 保留既有大 chunk 提示。

空白测试通过 WSL chroot 提供基础 shell、uname 与 OS 库，目标内无 Node、MonPM、C++ 标准库或下载/解压工具。SSH 协议测试服务与 Python/Node 测试夹具均位于根目录外，不向目标预装应用环境。执行密码认证、指纹核对、依赖上传、实际进程启动、无 DLC 接收方配对、双向文件同步和重复部署；检验身份、资料库及两个文件版本保留。目录含中文、单引号和 shell 字符，凭据不进入命令或状态。

初次强约束测试发现两项问题：夹具移除了 uname 本身需要的 OS libgcc，改为保留基础命令的真实依赖；运行包构建器误将 MonPM 作为 C++ 资源压缩，已修正实际文件选择并加入 ELF 类型/架构反例，旧错误包隔离为 rejected 证据。最终空白部署约 40 秒通过。原始证据、改动前副本、截图、日志和本地候选 DLC 位于根 .release/shared-host-empty-20261029。

构建器验证运行包缓存后复用，不重新编译未变 MonPM。Node 官方校验、Ubuntu 包校验、GPL 与 GCC Runtime Exception 许可证均随包记录；本机通过 socks5://127.0.0.1:10808 获取官方 GCC GitHub 镜像许可证，其他资源直接获取。没有 Git 源码推送、GitCode 分发或正式发行。

## 复现与边界

从 Agent 运行 `node --test Script/Project/shared_host_runtime_assets.test.mjs`。实际空白部署使用 `EDEN_SHARED_HOST_LINUX_NODE` 指向 WSL 内夹具专用 Node，再执行 `node --import tsx --test Script/Project/shared_host_wsl_ssh.test.mjs`。该 Node 只负责根目录外的测试服务，不是被测主机已有依赖。

开发机从根运行 `node Agent/Script/Project/build_shared_host_runtimes.mjs`，再执行 `node Agent/Script/Project/package_shared_workspace_dlc.mjs <新的输出目录>`。有效包校验复用，失败停止。完整使用说明见 DLC/SharedWorkspace/docs/cloud-host.md。

适配 x64/ARM64 GNU/Linux，私有 C++ 库面向 glibc 2.34+；Alpine/musl、32 位和 Windows 云端未适配。ARM64 完成构建、SHA 与 ELF 架构校验，尚未在 ARM64 硬件运行。真实公网 SSH、安全组、系统启动服务和重启恢复、物理双机及长时间运行仍待现场验收。客户安装、正式版本和客户归档未更新，未使用真实资料作为测试夹具。
