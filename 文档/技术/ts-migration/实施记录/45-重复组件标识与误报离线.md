# 重复组件标识与误报离线

用户报告 UUID 重复 key，并截图显示“Wait for the session to become idle before configuration”被标为后端离线。只读核对 UUID 是会话 ID；ChatPage 同级 MemoryCandidatesPanel 和 SubagentPanel 都以该 ID 为 key。

分别加 memory-/subagents- 前缀保留各组件稳定身份。session reducer 的 connectionError 不再强制修改连接状态，断线由订阅 onError 的 connectionState 决定；已连接状态下的操作错误在聊天区域作为非阻塞提示，不隐藏历史消息。

首次加载及重连刷新模型目录若遇到准确的 busy 配置拒绝，保留当前绑定、继续读取消息；其他异常继续提示，不绕过宿主配置锁。

前端类型检查通过。新增两项行为回归验证业务错误不置离线、真实断线/重连仍正常切换。未进行 Electron 实机验收。
