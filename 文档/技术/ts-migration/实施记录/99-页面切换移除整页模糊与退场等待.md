# 页面切换移除整页模糊与退场等待

日期：2026-09-18。

用户反馈全局配色调整后页面切换变卡。本轮静态排查确认主容器长期保留 `filter: blur(0px)`，聊天、备忘、自醒、角色选择等页具有整页模糊/位移动画，页面级 `AnimatePresence mode="wait"` 配置要求等待旧页退出。这些动画早于本轮配色调整存在；没有帧率对照证据，不能认定它们是本次性能变化的唯一原因。

## 调整

- 移除主容器 filter；用户主动设置的壁纸模糊保留。
- 页面切换直接替换组件，不再等待退场；移除没有共享布局元素的页面级 LayoutGroup。
- 新增统一 `pageEnterMotion`，九个页面采用 140ms opacity 淡入，不对整页进行 filter、位移和缩放。
- 对话框、图片预览及角色内部切换仍使用自身动画，数据加载、权限和账号逻辑不变。

## 验证

- 配色静态检查通过，224 个源码文件。
- `npm --prefix frontend/web run typecheck` 与前端差异格式检查通过。
- 未执行 UI 自动化、实际帧率采样或前后对照，因此不宣称卡顿已被完整复现或消除。当前改动消除已识别的页面切换额外开销，后续若仍卡顿需按具体页面定位数据加载、角色渲染和长任务。
