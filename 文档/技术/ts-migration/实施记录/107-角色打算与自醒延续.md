# 角色打算与自醒延续

日期：2026-09-18。用户批准实现“角色打算 + 下一步行动 + 完成记录”。

## 实现范围

新增 intentions 业务模块、API 输入 schema、SQLite 两张表及迁移。提供 list_intentions、read_intention、create_intention、update_intention 四个模型工具，默认接入日常对话与自醒，子智能体不提供这些工具。

打算记录标题、原因、下一步、状态及更新时间；追加进展记录保存说明、可选产物位置、来源会话与回合。支持 active / waiting / paused / completed / abandoned，最多同时五项 active 或 waiting，阻止同名未完成打算重复创建；重新激活时仍检查容量。默认查询未完成事项，也能查看暂停和已结束事项。详情返回最近二十条进展，完整历史保存在数据库。

复用 MemoryScopes 从当前运行输入与行动角色确定身份，使用会话账号归属和 characterId 双重限定读写，两个世界仍由数据库分离。写入使用已有 memory.write 权限请求，不新增自动放行；后台缺少权限时沿用拒绝行为。审批后复核角色范围，更新时检查宿主读取的版本，避免审批期间的并发覆盖，模型无需填写内部版本字段。

普通对话提示支持自然记录值得继续的兴趣；新增内置 eden-intentions 技能。自醒先查看已有打算，选择小步骤推进，等待条件无变化时可以休息；进展通过工具保存，日记留给个人经历与心情。时钟围绕下一步和约定设置，联系老师前核实当前联系状态。计划记录本身不产生文件、命令或外部通信权限。

## 事实边界

进展明确标为 character_report，完成状态是角色声明，产物位置不会被自动执行、下载或当作已经核验。工具执行事实仍由原执行记录提供。本轮没有预填莉音的兴趣、制造实际经历或改写历史日记。
