# 会话标题自动生成

日期：2026-09-17。

## 实现

- 新会话收到第一条真实用户文本后，立即从该文本生成本地回退标题，前端无需继续显示“新会话”。
- 宿主同时使用当前会话绑定的模型发起一次独立标题请求。请求不携带会话历史、工具、角色提示或运行时上下文，关闭推理并限制为 64 个输出 token。
- 标题模型要求使用用户消息的语言，只返回一行自然语言短标题。输入最多取 4096 个 Unicode 字符；结果清除终端控制字符、双向控制字符、换行、引号及常见“标题：”前缀。
- 模型标题异步生成，不阻塞主对话。请求失败、超时或取消时保留本地回退标题。
- 标题状态通过 `session.title_updated` 事件持久化并实时广播，来源区分为 `fallback`、`generated` 和 `user`。
- 模型结果只允许替换 `fallback`。用户手动重命名后，迟到的模型结果不能覆盖用户标题。
- 已有非空标题按用户标题兼容处理；压缩、后台任务以及已经命名的会话不会额外触发标题请求。

- 会话持久化、环境更新与中断恢复相关回归 5 项通过。
- Server TypeScript 类型检查通过。
- 修改文件 lint 无错误。
- 重启真实开发宿主后，通过当前 Core 登录账号、真实会话模型和 WebSocket RPC 创建独立空标题会话并提交首条消息。主对话完成 1 次模型请求，标题链路完成 1 次独立模型请求；标题事件依次为 `fallback`、`generated`，最终持久标题为“真实验收自动生成标题”，来源为 `generated`。
- 验收会话随后通过 `session.delete` 删除，数据库确认状态为 `deleted`；Mon readyz 保持正常、会话故障数为 0。
