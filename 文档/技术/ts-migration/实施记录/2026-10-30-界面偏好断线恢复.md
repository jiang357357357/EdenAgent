# 界面偏好断线恢复

日期：2026-10-30。正式版本仍为 1.11.7，本轮为开发前端修复。

## 问题与证据

截图中的滚动、背景和外观 GET 同时因 RPC 连接关闭失败；三个 hook 原先只在首次挂载或切换上下文时读取，连接恢复后没有重试，错误会一直保留。截图不足以确认具体关闭原因，因此不将其归因为服务崩溃。检查时伊甸园和尘世 `/healthz` 均为正常。

## 实现

- `preference-read.ts` 只为 `ui.preferences.get`、`ui.background.get`、`ui.appearance.get` 提供恢复。已知连接异常或这三个读取超时后，500ms 起指数退避，间隔最多 10 秒，成功即停止并清除错误。
- `AgentRpcError` 等业务拒绝、权限和协议错误直接显示，不作连接重试。底层 RPC 的写入结果未确认语义不变，设置保存和任务请求不会自动重发。
- 三个偏好 hook 通过账号、运行世界和凭据修订代数隔离读取；清理时取消定时器，迟到结果丢弃。背景和外观的读取还校验修改序号，避免覆盖用户新修改。
- 相同的恢复提示合并为一条，显示“正在重新读取界面设置”；已有连接恢复通知时不重复显示。保存及其他操作错误继续显示“操作未完成”。

## 验证

- 相关 Node 回归 37 项通过：新增只读恢复/取消和通知用例，保留连接诊断、会话恢复与未知执行结果边界验证。
- Edge 真实浏览器 1 项、四场景通过：断线后恢复已存值并清除提示；切换账号丢弃迟到响应；相同用户 ID 的凭据更新重新读取且保存失败不重放；权限拒绝不重试。使用隔离的 RPC 夹具，不读取真实用户数据库。
- Web `tsc --noEmit` 通过；主题 346 文件检查通过；架构 1379 文件、0 错误；隔离 Vite 生产构建通过，存在现有大 chunk 提醒。
- 本机 Vite 能返回新的恢复逻辑与通知代码，两个 Agent 服务健康；本轮未重启服务。未通过桌面控制观察真实窗口提示是否消失，浏览器截图仅为隔离夹具。
