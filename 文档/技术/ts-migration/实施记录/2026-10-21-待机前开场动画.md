# 待机前开场动画

后续视觉美化见[开场动画视觉优化](2026-10-21-开场动画视觉优化.md)；本记录保留首次接入的行为与验证证据。

按用户要求，在前端主窗口打开并进入待机教室前加入开场：深蓝渐变背景中，光点沿双层轨道移动，几何光环和星光逐渐汇聚，随后淡出显露高清教室。使用现有 Lucide 图标和 CSS 原生动画，不增加视频文件、自动音频或新的位图素材。

`StartupOpening` 与待机场景同时挂载，场景在遮罩下继续加载和预热。正常开场播放约 1.4 秒，高清场景就绪后再用 0.65 秒揭开；若加载较慢，保留不透明开场画面等待，不提前露出低清占位图。跳过按钮可以缩短播放等待，仍在场景准备好后揭开。系统设置减少动态效果时只显示静态过渡，场景就绪后直接进入，不强制播放或淡出。

开场期间待机控件与角色交互区域通过 `inert` 和 `aria-hidden` 隔离。独立的 `StartupLoginStage` 继续处理角色触摸后的登录与失败回退，并在开场未结束时保持登录内容隐藏。进入待机后切换昼夜、动作以及登录返回均不重新播放开场。辅助窗口继续使用原有入口，不显示主窗口开场。

类型检查、主题检查（315 文件）、Web 生产构建和 24 个启动源码模块门禁通过，零源码错误／提醒；构建仍有既有的大体积 chunk 提示。

执行 `node --experimental-strip-types --test tests/startup-opening-renderer.test.mjs`，真实 Electron 开场专项 6 个验收点全部通过，零页面／图形错误：受控阻塞素材时 CSS 动画确实前进、底层控件不可访问；跳过后继续遮住尚未就绪场景；三帧预热后显露；昼夜切换不重播；正常播放包含完整时长；减少动态效果使用静态遮罩且不执行淡出。已查看播放中、揭开时和手机静态过渡截图。证据 `.artifacts/startup-opening-20261021/` 包含实际截图和带时间戳的阶段观测。

以 `EDEN_STARTUP_EVIDENCE_NAME=startup-opening-regression-20261021` 执行 `node --experimental-strip-types --test tests/startup-entrance-renderer.test.mjs`，既有真实 Electron 37 个界面验收点全部通过，零页面／图形错误，覆盖辅助窗口、待机台词、角色旁欢迎气泡、九组动作、昼夜切换、返回、失败恢复和实际 App 登录。独立证据目录 `.artifacts/startup-opening-regression-20261021/`。
