# 125 联系历史改为真实对话窗口

2026-09-21，用户要求去掉邮件/通知等联系记录汇总，改为查看 QQ 最近十轮或最新会话最近三轮对话。

## 实现

- 删除 read_contact_history 模型工具、contactActivitySchema、发送记录聚合实现，以及 get_self_awake_context 的 recent_contacts 分区及其聚合实现。默认工具、子智能体读取策略、工具说明和内置联系技能同步更新，生产源码中不再引用旧模型入口。
- 新增 read_recent_conversation，返回同账号、同角色最新真实聊天中的最近三轮，包含用户原文、该角色最终文字回复、时间、回复可用状态和截断标记。后台自醒、内部交接和子智能体会话排除；其他账号及其他角色回复隔离。长消息上限各 8000 字符，不返回思考/工具输出。最新会话按最近真实用户输入确定，时间较久也可读取，不跨多个旧会话拼接。
- 自醒初始 recent_conversation 使用同一读取逻辑，不再注入跨会话五条用户单边摘录。
- read_qq_messages 改为无参数固定最近十轮，连续用户消息及随后的角色回复归为一轮，保留最新尚未获回复的用户轮次；内部按用户私聊目标分页取数，最多十页/千条、输出 256KiB 上限，分页到边界时舍弃不完整的最旧轮次并标示截断。移除模型任意翻旧分页的入口。
- 邮件/通知投递台账继续作为发送幂等与执行依据保存，本轮不删除底层发送事实，也不对发送渠道做额外改动。模型不再通过该设计批量读取其旧正文。

## 验证

12 项相关测试通过，包括 QQ 跨页拼接/连续消息归轮/最近十轮、旧聚合入口移除、权限拒绝、同账号同角色隔离、只选最新会话三轮、真实最终回复过滤、时钟/日记上下文回归及提示词约束。Server 与 Web 类型检查通过。

实际账号数据读取确认：莉音当前最新真实聊天只有两轮，因此返回两轮，均有用户原话与角色回复，不补造第三轮。真实 QQ 仍未配置，QQ 路径通过模拟 Core 数据验收，未宣称完成真实 QQ 联调。
