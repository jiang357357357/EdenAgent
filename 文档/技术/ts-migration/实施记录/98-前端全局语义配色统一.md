# 前端全局语义配色统一

日期：2026-09-18。

## 问题与范围

此前只修改全局 accent 和个别聊天组件，其他页面仍有大量白底、旧橙色悬停和深色文字硬编码。主聊天页重复声明调色板，Markdown 的主题绑定也仅在聊天页内生效，导致不同页面和弹窗显示不一致。

用户批准统一全局配色。工作区原有账号、界面背景、字号、自醒等修改继续保留；本次不修改后端业务或用户数据。

## 实现

- `frontend/web/src/theme.css` 成为唯一调色板，集中背景、表面、正文、边框、主按钮前景/交互状态、四类状态色、遮罩、代码和滚动条颜色。
- 当前默认深色雾紫，不新增主题切换配置。移除 `.interface-dark` 重复调色板；保留其原有字号调节作用。
- 页面及组件采用语义类：覆盖登录、世界选择、角色选择、聊天、配置、设置、插件、技能、连接器、备忘、自醒/日记、审批弹窗及桌宠气泡。
- Markdown、原生选项、滚动条、阴影与渐变统一引用主题。语音波形读取 CSS 计算后的强调色，不再固定橙色。
- 主按钮使用深色 `on-accent` 前景；状态提示保留成功/警告/错误/信息含义；桌宠透明根节点与用户透明度仍生效。
- 备忘和日记保留图片纹理及排版，改为主题深色叠层。角色资源、用户壁纸及操作系统提供的壁纸颜色仍是内容。
- 新增 `check:theme` 静态门禁并接入 Web 构建，扫描手写 TS/TSX/CSS 的固定色值、Tailwind 原始调色板和重复颜色定义。
- 使用规则见 [前端全局配色规范](../../Eden%20Agent%20前端全局配色规范.md)。
