# 自醒直接保存自然语言日记

2026-09-14，按用户要求移除最终 JSON 控制协议。

## 设计与实现

- 模型最终回复直接作为日记正文原样保存，默认标题“自醒日记”。正文无需 mood、action、next_wake 等固定字段。
- 完成回调只检查正文非空，在同一事务保存日记并完成运行；decision_json 为 NULL，不进入 awaiting_action，不触发第二次动作执行。
- 通知、拨号、提醒、定时仍使用对应工具，真实执行状态保留在调用记录。正文即使包含 JSON 动作或时间也仅作为文字保存。
- 删除上一轮新增的 JSON 包装解析器；不再围绕模型文本的 JSON 格式维护兼容逻辑。
- MonOs 状态响应兼容现有协议：从已保存日记生成仅包含 diary 的结果，不生成行动意图、打扰标记或下次时间。MonOs 已支持无时间建议时使用自身默认周期，并保留显式定时工具的计划。历史决策和历史待处理动作保留兼容读取，新的最终回复不产生它们。
- 前端展示日记与真实运行状态，没有当前想法/行动摘要的记录不再显示空占位。工具调用记录仍可查看。
