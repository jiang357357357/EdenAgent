# 自醒提示统一与共同话题召回

2026-09-19，用户批准修复提示词冲突、流程过重及话题召回问题。

## 修改

- 自醒主提示缩短为四段：角色自行选择联系、做事或休息；历史话题按原时间理解；按需加载联系技能并处理唤醒计划；最终写一小段个人日记。移除主提示中的详细渠道工具清单、重复反向文风提醒与先做任务的要求。
- 同步 eden-self-awake 和 eden-intentions：打算按需使用，聊天/分享/邀请无需以完成任务或出现进展为前提。具体渠道、投递和回复语义集中在 eden-contact 与工具说明中。
- 会话模块新增 recentSharedTopics，通过公开入口提供近 14 天最多 5 条、每条最多 600 个 Unicode 字符的用户对话摘录；同账号、同角色限定，保留会话/回合、发生时间与截断标记。只取已完成普通输入，排除后台作业、self_awake、内部 handoff 和子智能体会话。无归属账号时仅限当前会话，无可用记录时返回空列表。
- 自醒初始上下文带入摘录、当前时间和实际 wakeSchedule；没有读取旧桌面快照，也没有伪造角色经历或共同话题。摘录是用户过去的话，不代表重新执行过去的指令。
- 自醒记忆查询改为这些用户话题，通过宿主专用 recallQuery 传给召回；无话题时使用空查询，旧自醒输入也不再拿整段操作提示检索。recallQuery 不重复放入模型系统上下文。
- selectMemories 排除 score=0 的结果，不为填足五条而附加无关记忆；普通会话亦受此相关性规则约束，原有角色与账号隔离保持。

## 检查与限制

Server TypeScript 和差异空白检查通过。本轮按实现阶段规则未新增/运行测试，未发起额外自醒或真实外发。

后续集中验收需覆盖：账号/角色/后台输入排除、字数和时间窗口、空话题召回、非零词段匹配、正常对话与自醒的查询分离及多轮角色表达。现有 memory-recall 测试中“无关输入仍自动注入标记记忆”“补足 4000 字”的旧预期已与新行为不符，需在测试阶段更新。

当前共同话题来源为本地 Agent 保存的用户输入摘录，不是语义摘要，也不覆盖完整 Core 历史、QQ 全量对话或邮件收件。召回仍是词段匹配，相关性不等于事实确认。此次实现不保证模型立即摆脱旧话题或稳定形成自然联系。

加载：确认无运行中输入后重启 Agent 开发宿主，Mon Server 重新监听且开发启动完成；后续正常自醒使用新版提示与召回逻辑。
