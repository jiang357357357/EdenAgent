# 147 运行中会话强制移除

日期：2026-09-26

## 行为

- 聊天侧边栏允许在会话运行中点击移除，不再要求先等待停止。确认文案说明会话立即从列表隐藏、运行任务同时收到停止请求。
- `session.delete` 先持久化 `deleted` 状态并取消排队/待核对输入，不等待模型、附件验证或子任务结束；当前运行的控制器被中止，模型和子任务收到异步取消请求。`session.close` 保持原有等待空闲的行为。
- 前端记住已移除的会话 ID，过滤迟到的事件、消息加载、发送结果和列表刷新，避免已移除会话被旧响应重新显示。
- 保留数据库中的删除标记与审计记录；这是强制从会话列表移除，并非物理清除全部历史数据。已发生且不可取消的外部副作用不会因移除而撤销。

## 检查

Server 与 Web TypeScript 检查、差异空白检查通过。按当前业务优先约束，未编写或运行自动化/UI 测试，也未操作真实用户会话；运行中的 Windows 安装版尚未更新。
