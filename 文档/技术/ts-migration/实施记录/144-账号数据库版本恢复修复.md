# 144 账号数据库版本恢复修复

日期：2026-09-25

## 问题

Windows 启动日志在 `account.services` 阶段反复提示账号运行时无法恢复。只读检查截图所示账号的 SQLite `user_version` 为 124，而此前推送的主仓库代码仅含到 122 版迁移。`migrateDatabase` 会拒绝以旧宿主打开较新版数据库，因此账号数据保留，但该运行时无法启动。

## 修复

- 发布已在本地账号库使用的 123–125 版向前迁移：会话分类表、QQ 会话映射表及旧自醒/子智能体会话分类回填。保持数据库版本保护，不回退或清空现有数据。
- 账号分区导入时，显式恢复源库的会话分类，并用持久事件、作业和运行记录补齐历史后台会话分类。
- 旧格式转换创建自醒及子智能体会话时写入对应分类。

## 核对与限制

- 只读确认两个本地 Mon 账号库均为 124 版；未用真实用户数据库执行迁移或测试。
- 本次仅覆盖源码与静态检查；Windows 上重新构建、启动并确认账号恢复仍待实机验收。若依然失败，需记录完整的 `server.account.failure` 诊断行以识别下一处错误。
