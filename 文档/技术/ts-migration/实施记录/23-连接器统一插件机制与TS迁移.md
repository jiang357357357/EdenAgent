# 23：连接器统一插件机制与 TS 迁移

日期：2026-09-10。用户批准后实施，承接记录 22 的目录归并。本轮完成通用连接器插件机制、四个官方 TS worker、构建入口与文档更新，并完成 Linux 集中回归。

## 实现结果

- `@eden/plugin-sdk/connector` 提供定义、上下文、会话、帧协议、初始化、健康、查询、动作、事件和关闭。帧、队列、输出和日志读取有大小限制；错误不携带私有异常文本；协议关闭只清理一次。
- 统一插件包新增 `connector` 组件及 `runtime: node`，复用安装、版本选择、权限和组件启停表。运行完整不可变包快照，revision 绑定包内容。原 `native_worker` 保留显式协议兼容，不再获得游戏专用启动路径。
- 生命周期只调用 `launchComponent`，按照清单解析文件、身份及固定网络端点。移除宿主的四个游戏名称分支与专用启动器；官方发现、构建和发行均动态枚举包目录。
- 官方包可以在安装前浏览清单，但只能在统一插件仓库安装、批准和启用后执行。旧实例名解析到对应插件组件；新版本不继承旧资源授权。可选实例权限也不能超过当前插件版本授权。
- 四个官方 worker 改为 TS，游戏规则放在各自插件。保留游戏模组、Squirrel 桥接、HOI4 指标解析、日志重写/半行处理、Lichess 动作与合法走棋重放、OpenTTD 订阅/状态/请求关联/计划失败即停，以及 Victoria 快照和 ACK。
- Victoria 控制探针编写 TS/PowerShell 版本，命令文件、前台窗口确认、输入、ACK 和失败清理均由插件负责；要求文件写和独立桌面输入授权。当前宿主没有 Windows 连接器隔离器，不能把源码迁移当作实际 Windows 支持。
- 智能体使用已有工作区工具写入和构建包，`eden_connector_plugin` 提供说明、预览、安装和启停，不提供自授权限。安装消费确切预览快照，默认禁用；测试经现有命令/隔离权限流程执行。
- `build:server` 同时构建四个便携 Node 包。旧 Cargo 构建入口、独立原生连接器 CI、Linux/Windows Rust Server 启动兜底已替换。`--built` 启动仍使用统一 v2 数据选择，禁止复制旧数据库到新运行目录。
- 26 个旧 Native、worker 和 Cargo 文件校验归档，清单保存在 `Archive/2026-09-10-rust-connectors/source-sha256.json`。没有修改既有 Rust 宿主归档；当前活动 Server/连接器无 Rust 源码或 Cargo 依赖。桌面 Windows 指针观察器仍是另一项独立 Rust 组件。

## 测试中修正的问题

初次类型检查发现执行器环境函数中的误插入，已修正。注册文件读取加强时遗漏闭合括号，类型检查发现，但旧架构扫描没有拒绝语法错误；已补语法诊断和对应规则测试。

Lichess 初次隔离测试提前退出：Node 22 的 HTTP ESM 命名空间初始化了附带的 WebSocket/Undici 导出，与 jitless 下禁用 WebAssembly 冲突。改为读取 CommonJS HTTP 对象，避免初始化无关导出；复跑协议与完整回归通过，没有提高内存限额或共享宿主网络。

关闭检查补充了正常 shutdown 应答后退出及只关闭一次的行为。观察器事件 ID 计入完整观测内容摘要，避免同一游戏日期的不同观测复用 ID 后触发事件冲突。

真实 Lichess 账户、真实游戏实例、Windows/macOS 连接器隔离和 Victoria 3 真实前台窗口控制未运行。Windows 桌面指针观察器的 Rust 迁移不属于本轮连接器范围。以上限制已写入主 README、插件系统说明和长期计划，不把本轮称为全仓库无 Rust 或全部 OS 可用。
