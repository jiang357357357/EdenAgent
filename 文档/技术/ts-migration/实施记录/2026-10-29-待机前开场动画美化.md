# 待机前开场动画美化

用户要求继续优化进入待机页面之前的动画。范围限定于开场视觉和动效，不调整角色待机、登录或托盘触发条件。

## 视觉与实现

应用 `image-to-code` 和 `imagegen` 技能，先通过内置 `image_gen` 生成一张独立开场关键帧，再提取构图、颜色、字体、间距、图形和动效层次。参考图位于 `.artifacts/startup-opening-20261029/design-reference.png`，完整实际提示词及分析位于同目录 `design.json`。该图片是设计参考，不是实际运行截图。摄影式银河、云层和水面被简化为渐变、固定星点和椭圆线条；运行时没有引用生成位图。

保留 README 中的“我要在那里与你相会。”，使用宋体和轻微逐字错位入场。中央图形增加渐变月牙、向中心汇聚的十个光点、分段描出的外轨和倾斜内轨，外轨缓慢旋转。背景采用固定分布的 48 个星点、两道短流星、斜向光带、地平线和四层水纹；等待素材期间继续低幅度的呼吸、漂移和倒影起伏。字幕下增加细线和小星芒，跳过按钮弱化为右下角轻量文字，保留焦点和禁用状态。

动效主体改变透明度和变换，描边只作用于小范围 SVG。经文不使用模糊滤镜，底层待机场景也不新增模糊处理。开场图形使用 SVG 和 CSS，无新运行时图片、视频、网络字体或第三方依赖。样式按整体布局／退出、背景、中央图形拆为三份语义明确的文件。

## 时序和状态

`useStartupOpening`、`useStartupOpeningReplay` 和场景就绪链路保持现有实现。通常 0–0.6 秒开始聚光，1.5 秒左右图形描出；经文在约 0.58–1.315 秒逐字浮现，星线在约 1.6 秒完成。最低播放仍约 2.4 秒，揭开约 0.8 秒，不增加强制等待。跳过只缩短开场，场景未就绪时继续遮盖；托盘隐藏时暂停、窗口再次出现时重播继续沿用既有状态。

竖屏调整中央位置和字距，480px 以下短横屏缩小图形与间距。系统减少动态效果时关闭全部动画和过渡，并隐藏一次性的聚光粒子与流星，按既有就绪逻辑移除静态遮罩。
