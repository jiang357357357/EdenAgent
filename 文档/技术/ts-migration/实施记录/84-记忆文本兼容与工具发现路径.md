# 记忆文本兼容与工具发现路径

2026-09-14。依据最新会话 e4bc230f-29e8-4ec5-97cd-aada62a69b76 的只读记录分析并修复。

## 问题与修复

- 三轮自动记忆提取均报 `Model returned non-text content`。运行时此前拒绝所有非 text 块，包括合法 thinking 块。现在允许思考块但只提取 text；空最终文本、意外工具调用及未完成响应仍失败。历史提取响应未保存，无法确认三次响应的具体块类型；回归覆盖带思考的 SSE 响应。
- 拨号一轮共有 11 次主对话模型请求。模型先检查连接器，猜测 MCP runtimeId 为 default，失败后翻页找到设备工具。为减少查找往返，由已按角色权限过滤的工具注册表生成未加载工具的简短目录，通过 list_tools 的 promptHint 注入；ID 和首句说明直接取自注册表，不另建能力映射。完整 schema 仍由 load_tools 批量按需提供。技能摘要/说明保持独立，无需加载技能才能调用工具。
- 目录只列未加载工具，最多 96 项，每项首句最多 120 字符；更多条目按任务关键词搜索。现有加载接口即可使用目录 ID。目录只表示入口存在，不承诺设备在线或连接器可用。
- MCP 描述明确实例 ID 来自 list_mcp_servers。通话描述说明 Core 承接同一角色的语音通话、文字会话只能查询状态，不代表角色被替换。会话与参与者提示要求核实历史环境信息后再作为当前事实陈述。
