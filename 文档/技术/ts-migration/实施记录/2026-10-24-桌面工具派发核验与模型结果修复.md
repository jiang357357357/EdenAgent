# 桌面工具派发、核验与模型结果修复

## 问题与范围

用户要求修复最新会话中“7 次未知”及工具输出问题。原调用把驱动 unverifiable 与调用失败混在一起；即使自动观察读到文字，仍可能抛出 unknown 包装。动作结果附带整棵元素树、重复定位路径和截图，模型需要自行判断实际效果。只读原生查询也沿用“动作已送达，请重新观察”的提示。

本次修复宿主结果契约、定向核验、模型投影和内置技能，继续使用官方 Cua 0.28.0，不修改官方原生库，不重放原会话中的 QQ 操作。

## 结果契约

| 字段 | 含义 |
| --- | --- |
| kind | observation 或 action |
| execution.state | dispatched/refused/partial/uncertain/not_applicable，独立表示派发事实 |
| execution.driverStatus/driverEffect/route | 保留驱动原有状态、效果和路径 |
| verification.state | confirmed/partial/unconfirmed/mismatch/unavailable/not_executed/not_applicable |
| verification.scope/evidence | 核验的值、文字变化、界面条件、窗口状态或几何，以及实际证据 |
| observationReady | 为 true 时直接沿用附带观察的新引用 |
| nextAction | 下一步核对、观察、发现或选择支持路径 |

驱动返回 unverifiable/suspected_noop 且调用已结束时，execution 为 dispatched；没有效果证据则 verification 保持未确认，兼容 status 为 delivered。定向证据确认后才为 verified。真正 partial、无明确派发结果的 unknown、断线和取消继续保持不确定，不自动重试。完整宿主回执、观察和截图先进入审计，模型视图独立生成，不改既有用户历史行。动作后观察失败单列 observationError，不抹去已有派发事实。

只读成功结果使用 kind=observation、status=read，直接使用查询结果。文字不可读时 text=null、status=unavailable；部分文字用 complete=false 表示，不能与空字符串混同。

## 定向核验

- desktop_type 按明确控件或坐标命中的编辑区域读回。完整标量 value 不依赖全局树完整，也不要求只有一个 Edit。替换核对完整值；插入比较前后完整文字是否恰好增加一段文本，原本同文不能证明新输入成功。contenteditable 后代文本不足时只记 partial，历史消息中的同文不替代输入框。
- 兼容输入工具支持可选 expect 数组，最多四项，按 role/label/ancestors 唯一定位，支持 present、absent、text_equals、text_contains。缺失只有在完整树中才能证明 absent；歧义、降级和不完整文字不伪造确认。证据仅说明指定界面状态，changes.causalAttribution=not_established；既有同文气泡和本地界面不等同远端收件。
- desktop_read_text 不因同一进程窗口的动态 OS 标题单独拒绝。仅对应 OS 根的 Window 祖先可跟随实测标题更新，业务祖先仍严格匹配。返回 titleChanged、businessTargetUnchanged=not_established；业务区域变化、缺失和歧义仍拒绝。显式 expectedTitle 的输入前检查保留。
- 最大化、还原、最小化和激活增加独立原生状态读回，保留 resize 可见边界核验。还原已派发但仍最大化时 verification=mismatch，不报告恢复成功。
- 输入后只刷新观察，不重放动作。新引用替代旧引用，observationReady=true 时无需再 observe；暂停、停止和跨回合边界保留。

## 模型输出与技能

全部 66 项桌面工具登记独立模型投影，当前执行和历史结果重建共用投影。显式观察默认最多 80 个节点，支持 query/maxElements；动作观察默认最多 24 个节点，优先目标、变化、编辑和操作节点，并限制节点文本总量。保留可调用的新引用、parent/context、必要几何、能力和质量说明，省去重复完整路径及逐元素几何副本。omittedElements/outputTruncated 等说明省略，不能据此判断节点不存在。原生树省去重复 tree_text/tree_markdown，用户剪贴板和脚本业务内容不按树规则截断。

已完整派发且已确认的动作不再重复附加模型截图，原截图仍在审计。未确认结果保留截图引用；真正 partial/unknown 仍走现有运行时错误通道，不能据此承诺错误调用向模型附加图片。

说明集中在 Server/src/model-prompts/desktop-tools.ts、desktop-results.ts、cua-skill.ts。工具修订为 eden.desktop.cua.v6 / eden.cua.0.28.0.v2；仍为一个内置流程技能，参数按需展示，加载说明不控制执行可用性。
