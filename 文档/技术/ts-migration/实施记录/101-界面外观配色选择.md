# 界面外观配色选择

日期：2026-09-18。用户授权将全局配色对接界面外观。

## 实施

- 界面外观新增五组强调色按钮：雾紫、晴蓝、薄荷、玫瑰、暖金。选中态可见且有 aria-pressed；恢复默认外观同时恢复雾紫。
- theme.css 继续作为唯一色值来源，预设覆盖 accent、accent-hover、accent-active、accent-dim、on-accent。根节点属性使各页面和同文档弹窗即时继承，不引入整页模糊或重载。
- API 外观协议增加 accentTheme 枚举，旧输入默认 mist；存储沿用按账号/世界隔离的 runtime_settings，不新增数据库迁移，缺失或无效历史值回退雾紫。
- 外观 hook 持有当前选择并串行保存，过时响应不覆盖新选择；账号/世界切换使旧请求回调失效并重新读取偏好，读写失败使用现有错误展示路径。
- 本轮只开放强调色预设，不提供浅色主题、任意 HEX 编辑或独立桌宠窗口的跨窗口实时同步。
