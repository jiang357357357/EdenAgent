# 139 Core 登录过期与桌面校验竞态

2026-09-24，用户提供桌面登录页截图：旧会话失效后，页面直接显示 `Error invoking remote method 'eden-agent:invoke': Error: authentication_expired`。

## 原因

- Mon Core 的用户 Token 按活动滑动续期，超过 24 小时无活动或登录满 7 天才应失效。前端只保存登录或上次显式校验时的过期时间；到达本地时间便直接退出，可能误判仍有效的 Core 会话。
- 桌面主进程中，旧 Token 的异步校验在新登录完成后仍可能清空或覆盖新认证状态；渲染进程也可能用旧校验响应覆盖新 Token。
- Core 返回的过期标识通过 Electron IPC 原样进入登录页，未转换为用户可读提示。仅凭截图不能确认那次 Token 是自然到期还是被上述竞态误清。

## 修改

- 本地过期时间仅用于触发 Core 校验；只有 Core 确认失效才清理会话。临时网络故障保留原 Token，以便重试。
- 桌面端给认证状态增加修订号，旧校验结果不能改写新登录状态；已过本地时间的校验缓存不再作为有效结果返回。前端旧校验也不能覆盖已更换的 Token。
- 保存 Token、用户和过期时间后再广播账号变化；登录页把已确认的失效错误显示为“登录已失效，请重新登录。”

## 验收边界

本轮依项目当前要求仅完成源码和静态差异检查，未运行类型检查、自动化、构建或桌面真实登录验收；运行中的旧桌面进程尚未加载修改。Core 的 7 天强制重新登录规则保持有效。
