# 开场动画视觉优化

后续经文替换、主题光效修正及动作细化见[开场经文与动画细化](2026-10-21-开场经文与动画细化.md)。本记录保留首轮视觉优化的实现与证据。

按用户“开始优化美化动画”，优化进入待机教室前的开场。采用深色天空、斜向青色光带、稀疏星点、地平线与椭圆倒影；中心改为精细 SVG 双轨道、弧形光环与四角星芒。保留单行提示和右下角跳过按钮，沿用已经删减过的页面内容。

应用 image-to-code 技能，先使用内置 image_gen 生成单幅独立视觉参考，再提取构图、色彩、间距、控件和动作层次。参考图及完整提示词保存在 `.artifacts/startup-opening-polish-20261021/design-reference.png` 和 `design.json`；参考位图仅用于设计记录，应用实际由 CSS 渐变、已有主题变量和 SVG 绘制，没有新增运行时图片、视频或依赖。代码有意简化参考图的摄影式云层与水面纹理，保留其构图和光线关系。

模块：`frontend/web/src/pages/startup/StartupOpening.tsx`、`StartupOpeningArt.tsx` 和 `startup-opening.css`。装饰背景单独成组件，星点位置固定。主图在高度 43% 处，地平线在 73% 处；图形随视口缩放，短横屏收缩至 160px。光点亮起、轨道展开、字幕浮现之后，光环轻微放大并随遮罩淡出。主要动画只改变透明度和变换，局部静态光晕保留清晰 SVG 边缘；没有对底层教室施加模糊滤镜。

状态仍归 `useStartupOpening`：约 1.4 秒最低播放时间，场景就绪后 0.65 秒淡出；冷加载继续遮住尚未准备好的场景，跳过只缩短开场等待。系统减少动态效果时，包含伪元素在内的装饰均停止运动，静态遮罩在场景就绪后直接移除。加载失败沿用原登录回退；待机、昼夜、角色动作和登录返回不重播。

使用 Node 22.23.1 执行 Web `tsc --noEmit`、`scripts/check-theme.mjs`、Vite 构建，以及证据目录中的 `check-source.mjs`。全部通过：主题检查 316 文件，启动源码 25 模块，源码门禁零错误、零提醒；构建仍提示既有大体积 chunk。

以 `EDEN_STARTUP_EVIDENCE_NAME=startup-opening-polish-20261021` 执行 `node --experimental-strip-types --test tests/startup-opening-renderer.test.mjs`。真实 Electron 开场专项 7 点通过，零页面／图形错误。实际阻塞本地素材加载，验证动画前进、底层交互隔离、跳过仍保留遮罩、三帧预热后揭开、正常时长、昼夜不重播、减少动态效果。新增检查全部装饰停止动画，以及 390×844、844×390、1366×768 下主图、字幕与按钮完整处于视口且不相交。已查看实际播放帧、手机、横屏和笔记本截图。

以 `EDEN_STARTUP_EVIDENCE_NAME=startup-opening-polish-regression-20261021` 执行 `node --experimental-strip-types --test tests/startup-entrance-renderer.test.mjs`。既有 37 点真实 Electron 界面回归全部通过，耗时约 97 秒，零页面／图形错误；覆盖待机台词、角色旁登录气泡、昼夜九组动作、取消返回、缺少素材回退及实际 App 登录。证据独立保存在 `.artifacts/startup-opening-polish-regression-20261021/renderer-result.json`，原有开场证据未覆盖。

测试仅使用独立临时目录、本地素材和合成登录回执，不使用真实用户数据库。开发 Web 制品已更新；刷新开发客户端可查看开场。
