# 短对话完整压缩与命令调用记录

2026-09-11，用户要求短对话照常允许压缩，并显示前端发送命令的调用反馈。

## 实现

- 不增加长度限制。保留预算覆盖全部历史时，改为把完整问答交给压缩模型，清空 retainedTail，不再通过 split-turn 仅总结用户问候、保留整个助手回复。继续使用公开 SDK 与持久化钩子；摘要保存成功后接替原上下文，原审计不删除。
- `/compact` 的持久化 input.queued 事件投影为用户命令消息，包含原始附加指令；沿用现有回合忙碌状态，完成后显示摘要卡片。命令与结果各使用稳定事件 ID，实时和历史回放一致。命令消息只用于界面投影，不插入模型对话历史。
- 原因：ChatPage 已有其他斜杠命令的本地反馈，唯独跳过 `/compact` 等待服务端记录；缺少入队事件到消息的转换导致命令部分消失。本次补齐该路径，普通 prompt 入队事件不额外产生消息，避免重复。
- 其他打开设置、模型选择等 UI 命令继续沿用本地反馈；本次没有声称这些 UI 操作均已持久化。请求未被服务端接受时沿用现有输入区错误提示。
