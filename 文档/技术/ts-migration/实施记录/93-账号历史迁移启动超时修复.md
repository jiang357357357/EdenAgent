# 账号历史迁移启动超时修复

日期：2026-09-17。

## 原因与修复

用户执行 npm run dev 时 Local 启动成功，Mon 在监听前超过 60 秒。账号分区导入使用相关 EXISTS 子查询，为每个 Blob、每份 request_contents 再次遍历账号事件并解析 JSON。真实旧库只读统计：163630 条事件、642640029 字节事件正文、926 个 Blob、564 份请求正文。小规模迁移夹具未覆盖该性能问题。

改为仅遍历一次所属账号事件 JSON，将附件与请求正文引用提取到有联合主键的临时表，再按引用集合导入。请求 hash 只接受 requestStorage.references 数组中的字段；其他 hash 不授予访问权。保持事务、账号归属、复制附件和原库保留规则，不增加启动超时。

新增 legacy.database、legacy.ownership、account.import、account.services、account.background、account.ready 启动日志，定位监听前的初始化阶段。
