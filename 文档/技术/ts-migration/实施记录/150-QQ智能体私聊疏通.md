# QQ 智能体私聊疏通

日期：2026-09-26。当前仍限定 Bot 超级管理员私聊；本轮不扩大联系人权限。

- Agent Server 增加需要 Core 服务签名的 `/internal/channels/qq/availability`。按 Bot 与联系人查既有 QQ 会话；已有会话核对其绑定助手，新会话核对账号当前助手，并读取 Core 模型目录确认模型可用。跨账号请求仍拒绝。
- Core 在 `/模式 智能体` 前调用该入口。服务、助手或模型不可用时保留原模式；智能体回复由渠道层加 `【智能体】` 标识。非纯文本和过长输入在渠道层明确提示，不送入模型；没有 OneBot 消息 ID 时不借临时请求 ID 冒充幂等键。
- BotCore 聊天请求 ID 增加随机后缀；超时后带请求 ID 的迟到回复不进入通用回调，避免误投递。

本轮仅执行 Python AST 语法解析与各仓库 `git diff --check`，均通过。遵照当前实现阶段约束，未运行 Agent 类型检查、构建、自动化或真实 QQ 联调。已有同步等待仍约 3 分钟；持久入站/出站账本、断线恢复与真实 QQ 收发验收仍待后续实现。
