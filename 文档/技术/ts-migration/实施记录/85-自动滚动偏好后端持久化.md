# 自动滚动偏好后端持久化

2026-09-14，按用户要求将聊天工具栏的新消息自动滚动开关保存到后端。

- `packages/api` 定义 `ui.preferences.get/update` 严格布尔协议并生成客户端。
- `ui-preferences` 模块拥有读写，数据库新增 `ui_preferences` 单行表。默认开启，设置属于当前宿主世界，不依赖会话，也不写入 Core 或浏览器 localStorage。
- 前端登录及选择世界后读取，写入成功后更新开关，失败显示错误。读取和保存期间禁用按钮，切换世界后丢弃旧响应，避免相互污染。
- 删除切换会话时强制开启的旧逻辑。打开另一会话仍定位到最新消息，但后续是否跟随新消息遵循后端偏好。
- 设置对当前世界的客户端共享；其他已打开窗口在重新加载时读取最新值，本次不增加实时偏好广播。
- 临时数据库 RPC 集成测试覆盖默认值、关闭、数据库关闭重开后的恢复、非法输入拒绝和世界隔离，1/1 通过。未将真实用户数据库用作测试夹具。
- `npm run generate:rpc`、`npm run typecheck`、`npm run build:server`、`npm --prefix frontend/web run build` 通过；架构检查仅有既有两项 Mon 复杂度错误，Web 构建保留较大 chunk 提示。
