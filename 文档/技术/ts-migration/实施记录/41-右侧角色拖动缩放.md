# 右侧角色拖动缩放

用户要求增加开关，开启时拖动右侧当前角色并滚轮缩放。

聊天顶部新增移动图标按钮，按下状态表示调整开启；右侧显示操作提示、缩放百分比和重置按钮。指针捕获支持移出角色区域继续拖动；取消或失去捕获时结束拖动。调整层阻止角色原有点击响应；关闭或 Esc 后恢复。滚轮监听明确使用非 passive，阻止页面滚动。

位置按容器比例保存，缩放范围 25%—300%；按当前世界和角色 ID 存入浏览器本地存储，存储不可用时仍可本次调整。静态立绘和 Spine 共用外围变换层。切换角色关闭调整模式，独立组件避免主页面扩张交互逻辑。

验证：前端类型检查与 diff 检查；未进行 Electron 实机拖动验收。
