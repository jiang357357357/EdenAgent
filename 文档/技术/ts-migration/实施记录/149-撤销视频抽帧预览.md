# 149 撤销视频抽帧预览

日期：2026-09-26

## 实施

- 按用户要求撤销 `read_attachment` 的 `frames` 操作及其模型图像结果处理，删除 FFmpeg 抽帧实现和命令审批调用。
- 工具恢复为 `list`、`read` 两个操作，保留文本与 base64 分页读取；同步移除提示词中的视频预览描述。
- 视频文件仍沿用原有普通附件的上传和保存流程。当前工具不解析视频画面或音轨，也不将 MP4 作为模型原生视频输入。

## 验证

- 按当前业务实施约束，不运行自动化、媒体实播或 UI 测试。Server 类型检查与差异检查结果以本次执行记录为准。
