# 上下文来源分类与细项预览

2026-09-11，用户要求修复上下文窗口分组过粗的问题。

- 单角色和多角色构建端分别输出原系统提示和来源记录，按角色、系统、环境与附件分类；召回记忆单独记录，运行时追加实际工具指引及技能目录。来源仅写入审计快照，不进入模型请求；原提示文本和工具授权规则不变。
- 新增 contextSources 内容寻址存储支持，避免来源字段重复存储长文本。
- 已有快照只在精确匹配历史宿主模板、成功解析当时嵌入 JSON 后恢复来源，按已记录 promptHints 拆出实际技能指引；不读取当前角色配置来替代历史内容。未知/损坏格式原样保留并标注未记录来源分类。
- 窗口按角色人设、系统规则、技能目录、召回记忆、环境与会话信息、对话历史及工具交互、本次请求输入、工具定义分组。角色对象细化到字段，每个工具定义按名称单列；工具调用保留参数和 ID，返回内容和消息附加字段也可单独查看。当前草稿与完整原始请求继续保留。
- 每个细项显示字符数和短预览，展开查看完整内容，不再只有几个无预览的大折叠项。
