# 伊甸园账号独立存储与业务运行实例

日期：2026-09-17。

## 范围与边界

用户明确要求账号之间隔离，并确认“只隔离宿主存储和业务状态”。不恢复 OS 沙箱；终端、插件及普通文件访问仍按当前操作系统账户权限执行。用户主动选择同一本机项目目录也不构成独立文件系统。账号身份由配置 Core 验证，不接受前端传入任意账号标识来选择数据库。

## 实现

- Mon 根容器只负责监听、身份验证和账号运行实例生命周期；每个账号各自创建完整业务服务实例与数据库。Local 保持原有单实例。
- 存储为 `Data/realms/mon/v2/accounts/<SHA256(Core地址与用户ID)>/storage/eden-agent.db`。附件、连接器资源等随独立 dataRoot 保存，默认 workspace 与 skills 目录也分别创建。account.json 仅保存身份，不包含登录令牌。
- 会话、事件、记忆、备忘、自醒、审批、权限模式、插件草稿/安装/启用、技能、MCP、连接器凭据、语音配置和缓存、工作区选择、UI 偏好均使用账号独立数据库或运行实例。插件工作区授权的受保护目录包含所有已知账号存储；不改变已暂停的执行沙箱策略。
- WebSocket 初始化验证 Core 身份后固定绑定账号实例，周期复核身份；事件仅订阅该实例。Blob 与实时语音入口同样按已验证身份选实例。移除分区 RPC 路径对通用参数名/结果反射过滤的依赖。
- 同一账号并发连接复用实例；重启按持久身份恢复各自后台服务。单账号启动失败不回退到共享库，保留数据并使 readiness 报告异常；其他账号仍可连接。
- MonOs 签名入口、服务认证与外部自醒计划文件仅绑定配置的服务账号，不能由其他账号继承。其他账号持有自己的本地任务调度状态。

## 历史迁移

原共享库保留。只导入已确认账号归属的会话及可追溯关联记录，保留事件请求正文、附件文件、模型绑定、定时和自醒历史。事务提交前校验外键；附件缺失或归属不符则失败，不开放半迁移实例。复制附件而非共享硬链接。分区绑定账号键，迁移标记保证重复启动幂等。

无归属会话及旧全局插件、凭据、配置不自动分配或复制到各账号，继续保留旧库。账号需要重新配置原来无归属的设置。旧库不是在线业务数据库。

## 验证

- 临时旧库迁移：仅复制所属会话、记忆、备忘、自醒、附件及外置请求正文；不复制另一账号与未知全局配置；重复迁移与外键校验通过。
