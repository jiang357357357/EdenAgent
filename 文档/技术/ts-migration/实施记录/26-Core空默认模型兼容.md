# Core 空默认模型兼容

日期：2026-09-10。

模型菜单显示 Invalid request parameters，并同时显示没有可用模型。实际原因是 Core 的 `/api/agent/settings/my/` 返回 `default_model: ""` 表示未设置，TS 校验误将其作为非法模型 ID。与空白会话、角色立绘、沙箱策略无关。

将空白字符串归一化为 null，保留正常模型 ID 校验；Core 目录内数据校验异常改为明确的上游配置错误，不暴露返回数据或凭据。前端仅在请求成功且列表为空时显示没有可用模型。

对当前 Core 进行了只读目录查询，修复后返回 2 个可用模型，未修改模型绑定、未调用推理接口。12 项相关回归测试通过，服务端及前端类型检查通过。日志 `/tmp/eden-model-menu-fix.log`。开发服务需重启后加载服务端修改。
