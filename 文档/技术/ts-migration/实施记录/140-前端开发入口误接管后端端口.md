# 140 前端开发入口误接管后端端口

2026-09-24，用户在 `frontend/` 执行 `npm run dev` 时遇到 `127.0.0.1:40092 EADDRINUSE`。只读检查发现该端口由 MonPM 监管的已部署 Agent Server 监听；`frontend/package.json` 的 `dev` 错误地指向根目录 `Script/Project/dev.mjs`，该脚本会接管并重启双世界后端。MonPM 监管服务会重新占用固定端口，导致新进程绑定失败。后续的 `local Server exited before health check` 是启动器清理本批子进程时产生的连带错误。

将 `frontend/npm run dev` 改为调用已有 `Script/Project/dev_desktop.mjs`：启动 Web 和 Electron，Mon 世界使用现有外部服务；桌面壳管理尘世本地运行时。根目录 `npm run dev` 仍保留整套服务开发入口。实际监听的 MonPM 服务使用部署目录的 `v2/capability.token`，与源码目录默认文件不同；Linux 开发入口现从监听进程的 Mon 数据目录定位令牌文件，显式 `EDEN_AGENT_MON_TOKEN_FILE` 始终优先。前端 README 和脚本说明同步明确两者的范围。

本轮仅修改入口和文档、执行只读差异检查；按项目当前要求未运行构建、自动化或启动验收。当前运行中的 MonPM 服务未停止。
