## 实际发现并修正的问题

1. 提醒状态 SQL 的引号使整个宿主无法编译；修正字符串并增加状态持久化回归。
2. pi 无上下文泛型禁止提供 toolContext；改为显式的空对象上下文，保留公开 SDK 边界。新运行中刷新测试验证了下一次 HTTP 请求的工具目录和提示。
3. RPC 共用契约泛型、模型配置可选字段、子任务幂等键及前端可选/空值类型不同步；使用经过 schema 校验的类型和明确的边界映射修正，保留严格类型检查。
4. 客户端把旧服务端的 result/error 空占位响应判为矛盾。现在仅允许空的非活动分支，真正矛盾的双分支仍拒绝；重新生成客户端并验证实际服务连接。
5. ESM 构建产物包含 YAML 的 CommonJS 依赖，启动时 require(process) 失败。Server 构建增加标准 createRequire 桥接，产物已在两个独立进程中成功启动。
6. 会话视图丢弃已有 token 上下文字段；恢复可选协议字段和前端映射，不在缺少来源数据时生成假计数。
7. OpenTTD 桥接资源仍在归档中、Linux 入口仍指向已不存在的 Server 路径。将四份桥接脚本迁到 Connectors/official/openttd/bridge，入口改用当前路径，生产链路不依赖 Archive。
8. 旧测试未等待异步 RPC、SQL 插入依赖旧列数、插件替换未传草稿摘要，v18 升级夹具保留新版本表。修正这些夹具，维持原有失败/权限/数据断言；升级测试现在使用真实 v18 表结构。
9. Web 测试夹具缺少 window 事件、完整 initialize 响应和 JSON-RPC 版本，多个 Vite SSR 服务还争用默认 HMR 端口。补真实协议要求并关闭夹具 HMR，不放宽生产客户端校验；更新源码拆分后过时的静态接线断言。
