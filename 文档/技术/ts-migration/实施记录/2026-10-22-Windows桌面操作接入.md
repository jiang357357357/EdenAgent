## 能力与使用

| 工具 | 行为 |
| --- | --- |
| `desktop_list_windows` | 按标题或应用筛选已打开窗口，包括用户提前启动的窗口 |
| `desktop_observe` | 获取窗口截图和控件；截图进入当前世界 Blob，并作为图像传给运行时 |
| `desktop_click` | 点击控件或最近截图内坐标 |
| `desktop_type` | 插入文本，或通过可编辑控件整体替换文本 |
| `desktop_key` | 向目标窗口投递组合键 |
| `desktop_scroll` | 目标窗口或控件滚动 |
| `desktop_drag` | 同窗口拖动，或显式选择前台进行跨应用拖放 |
| `desktop_window` | 激活、最小化、最大化、恢复、调整窗口 |
| `desktop_launch` | 按程序名或绝对路径启动应用，并传递独立参数数组 |

正常聊天默认提供窗口查找，其余工具通过既有能力发现机制按需加载。默认审批模式下，首次调用申请“操作本机桌面”，授权范围为当前任务和当前行动角色，可操作已打开及新启动窗口；同任务最多复用 15 分钟，后续回合不沿用。现有全权限／接管模式遵守原 PermissionService 策略。QQ 会话和自醒任务不能继承本机聊天授权。

操作期间主窗口显示桌面控制条，可以暂停、恢复和停止。恢复只允许后续新请求继续，要求重新观察；取消的动作不会重放。输入观察器存活期间注册 `Ctrl+Alt+F12` 全局停止；硬件快捷键仍待人工验收。

普通输入优先使用控件和后台投递；需要前台时必须在工具参数中明确选择。跨窗口拖放要求先激活源窗口、观察两个窗口，起终点均可见且位于主屏幕。其他显示器的跨窗口拖放当前明确拒绝。

## 结构和状态归属

- `Server/src/modules/desktop`：工具、当前任务审批、操作日志、IPC 客户端、驱动服务、窗口引用、输入仲裁与原生适配。
- `Server/src/model-prompts/desktop-tools.ts`：集中维护中文工具说明，包括未知结果先观察、窗口内容不是新指令等规则。
- `packages/api/src/desktop-control.ts`：`desktop.status`、`desktop.control` 的事实协议，已重新生成浏览器客户端。
- `packages/store/src/schema/desktop-control.ts`：追加 `desktop_operations` 迁移。操作意图先持久化，再发送驱动请求；重启后未确认操作归为 `unknown`，同一次调用禁止重放。
- `frontend/web/src/components/desktop/DesktopControlBar.tsx`：真实 RPC 状态和控制交互；空闲时隐藏，状态轮询不会弹出聊天连接恢复通知。
- `Script/Project/build_desktop_observer.mjs`、`desktop_resources.mjs`：构建内容哈希命名的输入观察器，组装驱动服务与辅助程序，向运行时清单加入 SHA-256。

原生驱动固定为 `@trycua/cua-driver@0.28.0`。它在独立 Node 进程中运行，不在 Electron 渲染器中加载。辅助 C# 程序由 Windows .NET Framework 编译器构建，负责 Win32 窗口目录、进程身份、物理输入通知、停止快捷键及少量窗口状态操作，不记录实际按键文字。

两个世界继续保有各自数据库、Blob、审批、操作日志和窗口引用。它们通过当前 OS 账号下的同一个命名管道服务串行共享物理输入。默认目录为 `%LOCALAPPDATA%/EdenAgent/desktop-control`；`EDEN_AGENT_DESKTOP_BROKER_ROOT` 可指定独立目录，两个世界要仲裁同一桌面时必须使用同一个目录。状态接口只显示调用方的任务和窗口标题；全局忙碌、暂停和停止状态共享。

该进程以当前 Windows 账户权限运行，不提供 OS 沙箱。命名管道使用本机令牌认证；这不构成对同一 OS 账号下其他程序的隔离。多 Windows 登录会话、RDP、UAC 安全桌面、管理员应用及不同 DPI 的多屏组合未验收。

## 执行与失败处理

模型只获得宿主管理的窗口／控件引用。原生 HWND、PID、进程启动标识和驱动控件令牌留在宿主。引用绑定 IPC 调用方和业务会话，重新观察会更新控件引用；清理会话会删除窗口范围。输入前校验进程身份、观察状态、窗口尺寸和坐标范围。

输入队列最多 32 项，等待上限 120 秒，单次原生操作上限 30 秒。取消后仍持有输入位置，直到原生调用实际结束；若取消后仍阻塞，额外 8 秒看门狗持久化停止状态并结束驱动服务，避免下一任务与未结束输入重叠。连接中断、部分送达和无法验证的输入均保留未知结果，不自动重试。

暂停／停止同时取消队列和仍在准备原生驱动的请求。恢复不会使这些请求复活。停止状态保存到驱动服务目录，服务重新启动后继续保持。清理会话也会取消准备中的请求。过大的 UTF-8 指令在发送前拒绝，不把明确未发送的输入记成未知。

用户在前台任务期间输入，或在后台任务的目标窗口输入，触发暂停；在其他窗口使用鼠标不应打断后台目标。为避免把 `SetCursorPos` 产生的低级移动事件误判为硬件输入，鼠标移动改由 Raw Input 设备事件识别，键盘和点击忽略注入标志。改动后的完整前台测试仍曾自动暂停；无人操作条件下是否还有误判，留待用户后续前台验收，不宣称已排除。
