# 角色位置即时保存

用户报告重新打开后位置丢失。代码审查发现原实现使用 200ms effect 延迟保存且吞掉存储异常；尚未复现用户实际关闭窗口路径，因此不能认定该时间窗口是唯一原因。

调整：在拖动、滚轮、重置事件处理时同步写入并回读校验，使用 ref 跟踪最新值，移除 effect cleanup 写入，避免挂载读取触发覆盖；保存失败在角色窗口显示明确错误。沿用已有世界/角色存储键。

前端类型检查通过；3 项存储回归通过，涵盖即时读回、多次调整、世界隔离、旧键恢复、重置和写入失败。测试为独立存储适配器，不等同于 Electron 关闭重开验证。跨浏览器来源/不同 Electron profile 的共享持久化未实现。
