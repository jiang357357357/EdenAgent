# 运行诊断设置弹窗

2026-09-10。按用户要求将原会话管理更名为运行诊断，移至设置 → 高级设置，点击打开窗口显示模态弹窗。

用户随后明确要求保留聊天顶部入口并改为图标：标签栏恢复运行诊断图标按钮，悬停显示名称，点击复用同一模态弹窗；设置入口同时保留。原同步、操作审阅、MCP 记录保留在诊断窗口。弹窗默认选择当前会话，可切换其他已加载会话，空列表明确提示；切换会话重新挂载面板。使用浏览器原生 dialog 的顶层遮罩、焦点约束、Escape 关闭与焦点恢复，内容限高滚动，避免受标签栏或页面动画布局裁剪。世界变化时重建弹窗状态。

前端类型检查、diff 格式检查通过；未进行桌面实机弹窗验收。入口为应用内模态窗口，不新增 Electron 进程或独立系统窗口。
