# 119 日记清理与个人日记表达

日期：2026-09-20。

用户要求增加日记清理功能，将“工作日记”改为角色自己的日记，并先清空现有日记。

## 实现

- 新增 `self_awake.diaries.clear`，严格要求 `confirmClear: true`，删除范围由已认证账号与当前世界确定。清理全部分页、全部角色的日记，保留会话、执行记录和唤醒计划；重复清理返回 0，已完成任务的重复完成回调不会重新生成日记，新任务仍可正常保存。
- 自醒页面新增“清空日记”及原生 dialog 确认窗口，支持错误反馈、防重复提交与主题颜色。清理后失效旧列表请求，清除已缓存日记及执行弹窗；日记列表只分页包含日记的记录，并按标题/正文查询，空日记不再显示历史执行的总页数。
- 页面“工作日记”统一改为“日记”。主提示与自醒技能统一使用“最后写下自己的日记，留住此刻的心情、在意的人和想记住的小事。”时钟处理放在此前，维持简短正向引导。
- 失败信息留在执行记录，宿主不再将异常自动生成角色日记。

## 已授权数据清理

核对当前账号及无运行中输入后，在事务中只清除该账号的日记表记录：当前账号库 42 篇，旧 mon 根库 23 条副本。清理后及重启后只读复核：上述两个库与 local 库均为 0 篇。

这是日记集合的清理，不是对历史事件、会话、既有备份或记忆的安全擦除；这些记录按原用途保留。未创建替代日记或触发新的真实自醒。
