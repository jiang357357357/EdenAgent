## B5：OpenTTD 受限 Admin 通道（已编写，未测试）

- 新增宿主 Admin Unix socket 桥，每个实例只转发到已配置并授权的 127.0.0.1:adminPort；客户端不能提交另一个地址，连接数限制四组，建连十秒超时，流管道处理背压。
- socket 位于独立私有临时目录，通过只读挂载暴露给 worker；保留 bubblewrap 网络命名空间隔离，不授予主机网络。新连接检查实例 generation、当前授权和 worker 摘要，定期检查撤销并关闭全部既有连接。
- OpenTTD native 客户端增加独立 transport 模块，通过宿主指定的 MON_CONNECTOR_ADMIN_SOCKET 连接桥；不通过用户设置选择 socket。未提供 socket 时保留原生客户端既有 TCP 模式，TS 隔离启动路径始终指定桥。
- 生命周期接入显式 host/adminPort 的 OpenTTD 启动，按世界/实例读取私有密码，仅注入该身份 key 和 credential，覆写 guest passwordEnv；不继承宿主环境，也不挂载注册目录。进程退出、初始化失败、宿主取消均关闭桥并清理临时目录。
- 目前显式本地地址模式已编写；受管实例注册发现、显式环境变量兼容、Lichess HTTPS 通道、跨平台隔离仍待实现。撤销检测周期为两秒，不声称瞬时中断。未启动 socket/worker、连接游戏、构建或运行测试。

## B5：OpenTTD 受管实例注册发现（已编写，未测试）

- 增加 openttd-target 与 openttd-process，分别负责目标解析/有界注册文件读取及 Linux 进程身份核对；沿用旧注册结构，检查实例 ID、host/dedicated 模式、端口、启动时间和绝对路径。
- 无显式 host/adminPort 时可指定 instanceRegistry，要求相应 filesystem.read 许可。文件限 64 KiB，拒绝最终符号链接和私有 Data 路径，读取前后检查元数据；不挂载原始注册文件到 worker。
- 核对 /proc 启动 ticks、可执行文件和启动目标，避免 PID 复用；Admin 桥新连接及周期监控同时核对注册内容和进程身份，变化即关闭旧连接，由生命周期重试重新解析。文件权限撤销也停止旧桥。
- 页面补充显式地址与受管注册的配置说明。环境变量默认注册路径发现尚未迁移；目前需用户明确选择 instanceRegistry。原生 worker 收到解析后的本地端口，旧注册文件不被修改。
- 本轮未实际读取游戏注册文件或 /proc 游戏身份，未连接游戏、运行构建或测试。Lichess、MCP 及其余计划继续推进。

## B5：Lichess 固定目标 HTTPS 通道（已编写，未测试）

- 提取固定目标 TCP socket 桥，OpenTTD 继续限定本机 Admin 端口；Lichess 在授权后解析配置域名，将当前 worker 的连接限定到该 IP/端口，每次重启重新解析。DNS 等待支持宿主取消与十五秒超时。
- 增加 Lichess 隔离启动器，确认当前 generation、worker 摘要、身份凭据和精确 baseUrl 网络授权。兼容 HTTPS 与显式 loopback HTTP；拒绝 URL 内嵌凭据、query 和 fragment。不继承宿主代理环境。
- 根据本地 reqwest 0.12.28 源码确认 Unix socket 能保留 HTTPS TLS；worker 新 http_client 模块使用该能力，继续禁用重定向和代理。原挑战/棋局 NDJSON 流、走棋/聊天等既有动作共用该客户端，不将网络转发缩减为非流式接口。
- socket 只读挂载到 /network，worker 保留网络命名空间隔离；只注入当前身份令牌。通道上限 32 组连接，保留背压及撤销周期检查；初始化失败、退出和宿主取消关闭桥并清理目录。
- 生命周期现已分别接入四类官方 worker 的启动路径，实际可用性未验证；Lichess 并发棋局上限、断线恢复及跨平台网络通道仍需后续验收。MCP 等原计划范围未完成。本轮未 DNS 查询真实域名、联网、启动 worker、构建或运行测试。
