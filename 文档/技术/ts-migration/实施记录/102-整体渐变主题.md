# 整体渐变主题

日期：2026-09-18。用户要求整体配色支持米色、暖色、清绿色及渐变，并授权实现。

## 实施

- 界面外观新增奶油米色、暖杏桃色、清新浅绿、雾紫暮色、深色夜幕五套基础主题，各自可搭配原有五种强调色。
- 全部色值仍集中于 theme.css；基础主题联动渐变页面背景、卡片、输入框、边框、正文/辅助/禁用文字、滚动条和代码背景。浅色模式加深强调色与状态色，原生控件切换 color-scheme。
- 页面根节点采用 theme-page；渐变不铺到正文卡片内，不新增动画和模糊。自醒页根节点移除固定纸张背景覆盖，正文纹理仍保留。
- 新增主题渐变/背景图片选择，选基础主题切换到渐变，保留原壁纸及其参数；图片模式使用适合当前明暗的遮罩。渐变模式停用图片透明度与模糊等控件，CSS 隐藏图片伪元素。
- ui.appearance 新增 baseTheme 与 backgroundMode，沿用账号/世界持久化、请求队列和过期响应保护。历史字段缺失分别回退 night 与 wallpaper，恢复默认沿用原夜幕雾紫和壁纸。

## 验证边界

不新增数据库迁移，不读写真实用户数据；本轮不运行单元或 UI 测试。静态类型、构建及差异检查结果记录于实施跟踪。运行中的旧后端需重启加载新协议；尚未验证真实界面和独立桌宠窗口的跨窗口主题同步。

- `npm run generate:rpc`、`npm run typecheck:server` 通过。
- `npm --prefix frontend/web run build` 通过，含 229 文件配色门禁及 TypeScript；Vite 仍提示大于 500 kB 的 chunk。
- 前端、Server 与本轮 API 差异空白检查通过。
