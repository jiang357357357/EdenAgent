# QQ 工具调用进度与私聊审批

日期：2026-09-26。QQ 智能体仍仅面向当前 Bot 的超级管理员私聊。

- Agent 为 QQ 会话开放限定的内置网页、工作区、终端和提醒工具；插件、连接器、联系人、设备与技能工具不向 QQ 暴露。原有写入、执行和联网工具继续使用权限服务；文件读取、目录搜索、备忘列表等读取工具在 QQ 会话中增加单次审批。QQ 请求不继承应用端全局允许模式或持久授权。
- Agent 的签名状态接口按事件序号提供工具开始、完成和待审批更新，省略原始工具结果；签名审批接口核对账号、Bot、联系人、QQ 会话、运行中的输入和待处理权限。每个请求只能处理一次，不创建持久授权；等待 150 秒仍未处理时自动拒绝。
- Core 将简要进度和审批请求发到同一超级管理员私聊。管理员可引用具体审批提示，仅回复“同意”或“拒绝”；Core 按引用的 QQ 消息 ID 查找已投递提示中保存的请求 ID。`/审批 <请求ID> 同意|拒绝` 作为引用不可用时的备用命令；BotCore 对命令和普通回复都应用本地许可规则。普通、未引用的对话文字不能代替审批。连续工具审批期间，回复等待时间相应延长。
- 提示中保留工具名、操作对象和必要的命令/提醒摘要；不转发原始工具结果、文件正文或完整工具参数。命令及对象摘要做长度限制与常见凭据键遮盖。

BotCore 测试为 12 passed、8 subtests passed；Core 引用审批的 2 个隔离单元测试通过，覆盖正确绑定、无引用和引用其他消息时不审批；Core 改动文件 Python AST 解析通过，各仓库 `git diff --check` 通过。遵照当前实现阶段约束，未运行 Agent 类型检查、构建、自动化或真实 QQ 联调。QQ 收发、断线恢复和多次连续审批仍需真实环境验收；进度发送失败时该次审批会在 150 秒后拒绝。
